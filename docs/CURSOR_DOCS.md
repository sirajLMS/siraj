## 🛠️ Step-by-Step Setup Guide in Cursor IDE

1. Open **Cursor Settings**: `Cmd + Shift + P` (macOS) or `Ctrl + Shift + P` (Linux/Windows) ➔ **Cursor: Open Settings** ➔ **Features** ➔ **Docs**.
2. Click **+ Add new doc**.
3. Paste the **Direct Documentation URL** from the tables above.
4. Name the prefix (e.g. `nextjs`, `pothos`, `drizzle`, `mui`).
5. Type `@<doc-name>` in Cursor Chat or Editor to inject official doc context directly into AI prompts!
