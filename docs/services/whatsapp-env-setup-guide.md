# WhatsApp Cloud API — Environment & Credentials Setup Guide

This guide provides an end-to-end walkthrough for configuring Meta Developer App credentials and WhatsApp Business accounts for the Siraj LMS WhatsApp Cloud API integration.

---

## 1. Environment Variable Reference

These environment variables live in `.env` (and `.env.test` for running live integration test suites):

| Variable | Required For | Source | Example Format |
| :--- | :--- | :--- | :--- |
| `WHATSAPP_PROVIDER` | All | Static configuration | `cloud_api` |
| `WHATSAPP_APP_ID` | OAuth / ES / Webhooks | Meta App Dashboard (Basic Settings) | `1394595299442458` |
| `WHATSAPP_APP_SECRET` | Webhook HMAC verification | Meta App Dashboard (Basic Settings) | `0a017f6a021e36550fb956daa4a88838` |
| `WHATSAPP_VERIFY_TOKEN` | Webhook GET handshake | Custom random secret (generated by you) | `c094b8d5caa8478dcf782e3b6f8bc322` |
| `WHATSAPP_ACCESS_TOKEN` | Outbound messages / Sync | Meta Business Suite (System User token) | `EAAT0Y...` |
| `WHATSAPP_PHONE_NUMBER_ID`| Outbound messages | WhatsApp Manager / API Setup | `1320980597762969` |
| `WHATSAPP_WABA_ID` | Template & number sync | WhatsApp Manager / API Setup | `2436434150218393` |
| `WHATSAPP_API_VERSION` | Graph API calls | Default version | `v26.0` |
| `WHATSAPP_GRAPH_API_VERSION` | Graph API calls | Default version | `v26.0` |
| `WHATSAPP_WEBHOOK_BASE_URL`| Production webhooks | Deployed application domain | `https://your-domain.com/api/webhooks/whatsapp` |

## 2. Meta App Creation & Use Case Selection

Meta's developer portal uses a **Use Case Architecture**. Selecting the wrong use case (such as Threads or Gaming) will completely hide the WhatsApp product and API Setup menus.

1. Go to [Meta for Developers Apps](https://developers.facebook.com/apps).
2. Click **Create App**.
3. Under "What do you want your app to do?", select:  
   **"Connect with customers through WhatsApp"**.
4. Enter your app name (e.g., `siraj-lms`) and your contact email.
5. Select your **Business Portfolio** (Meta Business Account).
6. Click **Create app**.

### Retrieving App ID and App Secret
1. In your App Dashboard, navigate to **App settings** ➡️ **Basic**.
2. Copy **App ID** ➡️ `WHATSAPP_APP_ID`.
3. Click **Show** next to **App secret**, enter your password, and copy it ➡️ `WHATSAPP_APP_SECRET`.

## 3. Webhook Configuration (`WHATSAPP_VERIFY_TOKEN`)

The webhook verifies incoming events (e.g., delivery receipts, message status updates, and inbound messages) from Meta.

1. Generate a secure random token (e.g. `openssl rand -hex 20`).
2. Add it to `.env` as `WHATSAPP_VERIFY_TOKEN`.
3. In Meta Developer Dashboard:
   - Navigate to **WhatsApp** ➡️ **Configuration**.
   - Under **Webhook**, click **Edit**.
   - **Callback URL**: `https://<your-domain>/api/webhooks/whatsapp` (or ngrok/tunnel URL for local dev).
   - **Verify token**: Enter the exact same string from `WHATSAPP_VERIFY_TOKEN`.
   - Click **Verify and Save**.
4. Under **Webhook fields**, click **Manage** and subscribe to:
   - `messages`
   - `message_template_status_update`
   - `phone_number_quality_update`
   - `account_update`

## 4. Phone Number ID & WABA ID (`WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_WABA_ID`)

You can find both identifiers directly in **WhatsApp Manager**:

1. Open [WhatsApp Manager](https://business.facebook.com/latest/whatsapp_manager/).
2. In the left navigation menu, click **Account tools** ➡️ **Phone numbers**.
3. In the phone numbers table:
   - The **Phone number ID** column contains your numeric `WHATSAPP_PHONE_NUMBER_ID`.
   - The URL parameter `asset_id=<WABA_ID>` or the account header displays your `WHATSAPP_WABA_ID`.

### Test Phone Number vs Production Phone Number
- **Test numbers** (e.g., `+1 555-xxx`): Provided automatically for development. They can only send to verified recipient numbers added to your dashboard allowlist.
- **Production numbers**: Real phone numbers added to your WABA. Must be verified via SMS or voice call, and registered with a 6-digit PIN.

## 5. Permanent Access Token (`WHATSAPP_ACCESS_TOKEN`)

Temporary tokens from the API Setup panel expire after 24 hours. Production and staging environments require a **Permanent System User Token**:

1. Open [Meta Business Settings > System Users](https://business.facebook.com/settings/system-users).
2. Click **Add** to create a system user:
   - Name: `siraj-whatsapp-system-user`
   - Role: **Admin**
3. Select the created system user and click **Assign Assets**:
   - **Apps**: Select your Meta App ➡️ enable **Full control** (Manage app).
   - **WhatsApp Accounts**: Select your WABA ➡️ enable **Full control** (Manage WhatsApp account).
   - Click **Save Changes**.
4. Click **Generate New Token**:
   - Select your App from the dropdown.
   - **Token Expiration**: Select **Never**.
   - Select the required permissions:
     - `whatsapp_business_messaging`
     - `whatsapp_business_management`
   - Click **Generate Token**.
5. Copy the generated token immediately and store it as `WHATSAPP_ACCESS_TOKEN` in `.env`.

## 6. Phone Number Cloud API Registration (Error 133010)

Before a phone number can send or receive messages via the Cloud API, it must be registered. If you attempt to send a message prior to registration, Meta returns:
`(#133010) Account not registered`

To register a phone number:
```bash
curl -X POST "https://graph.facebook.com/v26.0/<WHATSAPP_PHONE_NUMBER_ID>/register" \
  -H "Authorization: Bearer <WHATSAPP_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messaging_product": "whatsapp",
    "pin": "123456"
  }'
```
Response upon success:
```json
{ "success": true }
```

## 7. Recipient Number Allowlist for Test Numbers (Error 131030)

When using a Meta test number (`+1 555-...`), Meta will only deliver messages to pre-approved recipient numbers. Sending to an unverified number yields:
`(#131030) Recipient phone number not in allowed list`

To allowlist your test recipient:
1. In the Meta Developer Dashboard, navigate to **WhatsApp** ➡️ **API Setup**.
2. Under **Step 2: Send and receive messages**, locate the **To** dropdown.
3. Click **Manage phone number list** (or select "Add recipient phone number").
4. Enter your personal phone number (with country code) and verify the 6-digit code received via WhatsApp/SMS.
5. Once verified, Cloud API messages sent to this recipient will succeed.
*(Note: Production phone numbers do not have this restriction and can send to any valid WhatsApp user).*
