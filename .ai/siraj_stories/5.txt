1. Admin Notifications & Unpaid Invoices Tracking

User Stories

As an Admin, I want to click a notifications bell icon so that I can view incoming complaints or important system alerts.

As an Admin, I want to view a list of "Unpaid Invoices" from the notification tray so that I can instantly identify which users have overdue or pending payments.

As an Admin, I want to click on a specific user's name within the unpaid invoices list so that the system routes me directly to their account profile to follow up on billing.

Actions & Expected Outcomes

Action Taken: Admin clicks the notification bell icon (labeled/described as "Complaints" or Notifications) in the top right header.

Expected Input: Mouse click event.

Expected Result: A modal or dropdown renders displaying an "Unpaid Invoices" section.

Condition 1 (No Invoices): If all accounts are settled, it displays a placeholder message: "There is no invoices to be paid."

Condition 2 (Pending Invoices): If invoices are due, it lists the specific names of the users who are delayed in payment.

Action Taken: Admin clicks a specific user's name link within the populated Unpaid Invoices list.

Expected Input: Mouse click on a user link.

Expected Result: The system redirects the Admin to that specific user's detailed account/billing page to manage the outstanding invoice.

2. Schedule Search - Finding Available Teaching Slots

User Stories

As an Admin, I want to navigate to a dedicated "Schedule Search" tool so that I can find empty time slots across the academy's entire teaching staff.

As an Admin, I want to query the schedules by defining a specific time window (e.g., 5:00 AM to 12:00 PM) and a preferred teacher gender so that I can find a precise match for a student's requirements.

As an Admin, I want the search results to display visual, weekly calendar blocks for each matching teacher so that I can easily spot the empty gaps in their schedules.

Actions & Expected Outcomes

Action Taken: Admin clicks "Schedule Search" from the main sidebar navigation menu.

Expected Input: Mouse click event.

Expected Result: The system navigates to the Schedule Search view (/search-schedule.php), mounting a form with "From" time, "To" time, and "Gender" dropdown inputs.

Action Taken: Admin inputs a specific time range using the time pickers, selects a gender preference, and clicks "SUBMIT".

Expected Input: From time (e.g., 05:00 AM), To time (e.g., 12:00 PM), Gender selection (Any, Male, or Female).

Expected Result: The system queries all teacher schedules based on the parameters. The UI re-renders to display a "Search Results" section containing weekly schedule grids for each matching teacher (e.g., "Doaa Khaled", "Abdullah Fekry"). These grids only display the classes that fall within the requested time block, making the blank spaces (available slots) highly visible to the Admin.
