1. Parent Profile & Account Management

User Stories

As an Admin, I want to view a comprehensive profile for a specific parent so that I have access to their contact details, timezone, and billing information in one place.

As an Admin, I want to click a "Deactivate Account" button so that I can suspend a parent's access to the system if they are no longer active or have severely breached policies.

Actions & Expected Outcomes

Action Taken: Admin clicks on a specific parent's row within the Parents List directory.

Expected Input: Mouse click event on the parent record.

Expected Result: The system routes the Admin to the Parent Profile page. This page mounts multiple sections displaying: Parent Information (Name, Email, Country, Nationality, Phone), Social Media Links, and Fees Details (Invoice Type, Fee, Payment Method, Currency).

Action Taken: Admin clicks the "Deactivate Account" tab/button located in the profile header navigation.

Expected Input: Mouse click event.

Expected Result: A confirmation prompt mounts displaying: "Are you sure that you want to deactivate this account?" with "YES" and "NO" options. Clicking "YES" updates the parent's status to deactivated and restricts their login access.

2. Managing Associated Students & Class Quotas

User Stories

As an Admin, I want to view a list of all students associated with a specific parent so that I can quickly audit their individual assigned teachers, hours per week, and remaining classes.

As an Admin, I want to manually edit a student's "Classes Left" quota so that I can adjust their remaining balance in case of special circumstances, disputes, or manual renewals.

Actions & Expected Outcomes

Action Taken: Admin scrolls to the "Parent's Students" section on the Parent Profile page.

Expected Input: None (Page Load/Scroll).

Expected Result: A data table renders listing the parent's children. Columns include Student Name, Teacher, Hours a Week, Classes Left (e.g., 12 / 12), Language, Gender, Date of Birth, Info, Options, and Status.

Action Taken: Admin clicks the "Edit" (pencil) icon under the Options column for a specific student (e.g., "Eyad").

Expected Input: Mouse click event passing the Student ID.

Expected Result: The system routes to the "Edit Student Profile" view, mounting a form pre-populated with Student Information and Course Details.

Action Taken: Admin modifies the "Classes Left" numerical input field (e.g., changing it from 12 to 10) and clicks "Save".

Expected Input: Integer value (e.g., 10).

Expected Result: The system updates the student's available class quota in the database. The form submits, and the updated quota will reflect on the student's main record and affect when they next require an invoice/renewal.

3. Parent Invoicing & Document Management

User Stories

As an Admin, I want to view a dedicated "Invoices" tab within the parent profile so that I can audit their payment history, outstanding dues, and issue dates.

As an Admin, I want to access an "Upload Docs" tab so that I can attach external files (like identity documents or signed contracts) directly to the parent's record.

Actions & Expected Outcomes

Action Taken: Admin clicks the "Invoices" tab in the profile header navigation.

Expected Input: Mouse click event.

Expected Result: The profile view switches to an Invoices table. It fetches and renders the parent's billing history with the following columns: #, Month, Issue Date, Due Date, Paid Date, Fee, Status, and Options. If no invoices exist, it renders an empty state message: "You don't have invoices."

Action Taken: Admin clicks the "Upload Docs" tab in the profile header navigation.

Expected Input: Mouse click event.

Expected Result: The view switches to a document management interface, allowing the admin to upload file attachments securely linked to this specific parent's account.
