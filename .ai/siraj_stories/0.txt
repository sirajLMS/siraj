1. Authentication

User Stories

As an user, I want to securely log into the system using my email/username and password so that I can access the dashboard.

Actions & Expected Outcomes

Action Taken: User fills in credentials and clicks "SIGNIN".

Expected Input: Username/email (string), Password (string).

Expected Result: The system validates the credentials against the database. Upon success, the user is authenticated, assigned an active session, and redirected to the Home Dashboard (/dashboard).

2. Admin Dashboard - "Today Classes" Metrics & Quick Filters

User Stories

As an Admin, I want to view a comprehensive grid of metric cards summarizing the status of all classes for the day (e.g., Total, Regular, Trial, Pending, Running, Taken, Absent) so that I have a real-time, high-level overview of academy operations.

As an Admin, I want to click on any specific metric card (e.g., "Trial" or "Pending") so that the daily schedule table instantly filters to show only the classes matching that specific status.

Actions & Expected Outcomes

Action Taken: User navigates to the Home Dashboard.

Expected Input: None (Page Load).

Expected Result: The system fetches today's class data and aggregates the counts for the following predefined statuses: Total, Regular, Trial, Advance, Re Scheduled, Suspended, Taken, Pending, Actived, Running, Absent, and Leave. The UI renders these counts inside interactive statistic cards.

Action Taken: User clicks on a specific metric card (e.g., the "Trial" card showing '0').

Expected Input: Mouse click event on the card component.

Expected Result: The state of the class list table updates to filter records by the selected status. If no records match (e.g., 0 Trial classes), the table displays a placeholder state: "There is no classes today."

3. Admin Dashboard - Class List & Advanced Form Filtering

User Stories

As an Admin, I want to filter the class schedule by a specific date and a specific teacher so that I can look ahead, look back, or audit an individual staff member's workload.

As an Admin, I want to view the filtered schedule in a structured table displaying relevant class details (Time, Duration, Teacher, Student, Status) so that I can track individual session progress.

Actions & Expected Outcomes

Action Taken: User selects a date from the "List of Classes on:" date picker and selects a teacher from the "Teacher:" dropdown, then clicks "SUBMIT".

Expected Input: Date string (e.g., "10/30/2024"), Teacher ID (from dropdown selection).

Expected Result: The system executes a query with the selected date and teacher parameters. The schedule table re-renders to display the fetched classes.

Action Taken: User views the populated data table.

Expected Input: None.

Expected Result: The table displays rows with the following column structure: #, Your Time, Student Time, Duration, Teacher, Student, History (Action Button), and Class Status (Badge).
