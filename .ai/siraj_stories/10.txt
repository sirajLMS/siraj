1. Advanced Student Status Controls - Suspended

User Stories

As an Admin, I want to change a student's status to "Suspended" so that all their upcoming classes are immediately halted and their system access is revoked.

As an Admin, I want a "Suspended" student's classes to still appear on the Teacher's schedule but be completely disabled, so that the teacher knows the class is cancelled and cannot mistakenly start or interact with it.

Actions & Expected Outcomes

Action Taken: Admin navigates to the "Parent's Students" data table, clicks the status text (e.g., "Regular") for a specific student, selects "Suspended" from the dropdown menu, and clicks "SUBMIT".

Expected Input: Dropdown selection (Suspended).

Expected Result: The student's global status updates to "Suspended".

Action Taken: Teacher (or Admin impersonating Teacher) views their daily/weekly schedule containing the suspended student's class.

Expected Input: None (Page Load).

Expected Result: The scheduled class appears on the list, but its Class Status badge reads "Suspended". All action buttons (Activate, Start, Absent, Leave) are completely hidden or disabled, preventing the teacher from initiating the virtual room or modifying the class record.

2. Advanced Student Status Controls - On Leave

User Stories

As an Admin, I want to change a student's status to "On Leave" (e.g., for a one-month vacation or illness) so that their upcoming classes are flagged as excused absences rather than being fully cancelled.

As an Admin, I want the system to automatically generate reschedule requests for all classes missed while a student is "On Leave" so that the student does not lose the classes they paid for.

Actions & Expected Outcomes

Action Taken: Admin clicks the status text for a specific student, selects "On Leave" from the dropdown menu, and clicks "SUBMIT".

Expected Input: Dropdown selection (On Leave).

Expected Result: The student's global status updates to "On Leave".

Action Taken: The system evaluates the upcoming classes for the "On Leave" student.

Expected Input: System cron job or state evaluation upon status change.

Expected Result: Unlike "Suspended" classes which are locked, classes for "On Leave" students are treated as formally excused. The system retains these classes in the schedule but flags them to be formally rescheduled (similar to the Teacher Leave workflow) once the student returns to "Regular" status, ensuring their package quota is preserved.
