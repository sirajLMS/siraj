## Siraj LMS - Permissions & Permission Groups (Part 1: 00:00 - 02:01)

### 1. Permission Groups (Roles)

To simplify assignment, individual permissions are bundled into the following default system roles:

| Permission Group | Description | Assigned Permissions |
| --- | --- | --- |
| **All Authenticated Users** | Baseline permissions granted to anyone securely logged into the system. | `auth.login`, `auth.view_own_profile` |
| **Academy Admin** | Full operational oversight, real-time tracking, metrics viewing, and schedule auditing. | All `auth.*`, `dashboard.view_metrics`, `dashboard.filter_metrics`, `schedule.view_list`, `schedule.filter_advanced` |

---

### 2. Granular Permissions Breakdown

#### Group 1: Authentication (`auth`)

Controls baseline entry and identity verification within the LMS.

* **`auth.login`**
* **Description:** Allows a user to submit credentials to the authentication endpoint, generate an active session, and access the base system.
* **Expected Outcome:** Validates input strings against the database, provisions a session token, and permits redirection to `/dashboard`.


* **`auth.view_own_profile`**
* **Description:** Allows the authenticated user to view their own basic session and account details upon redirect.



#### Group 2: Dashboard Metrics (`dashboard`)

Controls access to high-level operational summaries and quick-filtering tools.

* **`dashboard.view_metrics`**
* **Description:** Grants the ability to view the real-time "Today Classes" comprehensive metric grid.
* **Expected Outcome:** Triggers the system query to fetch and aggregate today's data into interactive statistic cards (Total, Regular, Trial, Advance, Re Scheduled, Suspended, Taken, Pending, Actived, Running, Absent, Leave).


* **`dashboard.filter_metrics`**
* **Description:** Allows the user to click metric cards to interactively filter the UI state.
* **Expected Outcome:** Updates the daily schedule table view based on the clicked status card, including rendering the empty placeholder state ("There is no classes today.") if counts are zero.



#### Group 3: Schedule Management (`schedule`)

Controls access to deep-dive class auditing, data tables, and advanced filtering.

* **`schedule.view_list`**
* **Description:** Grants access to view the structured daily class schedule data table.
* **Expected Outcome:** Renders columns containing data for: `#`, `Your Time`, `Student Time`, `Duration`, `Teacher`, `Student`, `History (Action Button)`, and `Class Status (Badge)`.


* **`schedule.filter_advanced`**
* **Description:** Grants the ability to query the schedule database using advanced parameters (Dates and Teacher IDs).
* **Expected Outcome:** Authorizes the input of custom date strings and Teacher dropdown selections to execute a filtered database query and re-render the schedule table.
