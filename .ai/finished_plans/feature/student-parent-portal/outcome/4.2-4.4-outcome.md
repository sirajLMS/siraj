## Carry-forward knowledge
- Mobile/Desktop isolation pattern: Container + ViewModel in `frontend/common/views/`, tier views in `frontend/desktop/views/` + `frontend/mobile/views/`; `createLazyView` + `ResponsiveViewSwitch` for lazy loading.
- MUI Typography `fontWeight` must use `sx={{ fontWeight: 600 }}` (numeric in sx), NOT the `fontWeight` prop (causes TS2769 overload error). Codebase convention confirmed.
- `local/no-hardcoded-colors` lint rule flags `color="text.secondary"` — use `sx={theme => ({ color: theme.palette.text.secondary })}` theme callback instead.
- `sonarjs/no-nested-conditional` flags `a ? b : c ? d : e` — extract into a helper component that early-returns.
- `react/no-array-index-key` — use a stable key (field.label, student.id) not array index.
- `no-unsafe-type-assertion` — use `el instanceof HTMLInputElement` type guard instead of `as HTMLInputElement`.
- Codegen GraphQL types are nullable (`string | null`) — always default to `""` or `null` when mapping to ViewModel.
- Teacher profile-complete gate requires `national_id` (not just phone) — set via SQL for demo users.
- `myMonthlyAppraisal` query `month` variable must be a full ISO timestamp (e.g. `new Date(year, month, 1).toISOString()`), not a date-only string.
