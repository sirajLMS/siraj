file's actual idiom:

## Circular import note

`backend/db/schema/teachers/carryover-balances.ts` already imports
`classInstances` from `scheduling.ts`, so adding the reverse import creates a
two-way module cycle between schema files. This is an established pattern in
the schema layer (`scheduling.ts` ↔ `students/students.ts`,
`scheduling.ts` ↔ `billing/quota-ledger.ts`) and is safe because all FK
references are lazy `() => table.column` thunks consumed after module
initialization. tsgo (project-wide) and the full sub-loop pass confirm it.
