## Document names vs plan shorthand

The plan lists SCREAMING_SNAKE names (`CARRYOVER_BALANCES_QUERY`, …) but the
sharedDocuments layer convention (`frontend/common/graphql/sharedDocuments/AGENTS.md`)
mandates `{camelCase}QueryDocument` / `{camelCase}MutationDocument` constants typed as
`TypedDocumentNode<{Op}Query, {Op}QueryVariables>`. Followed the layer convention.
Mapping for downstream tasks (4.2, 5.1, 5.2):

| Plan shorthand | Exported constant | GraphQL operation |
|---|---|---|
| `CARRYOVER_BALANCES_QUERY` | `carryoverBalancesQueryDocument` | `query CarryoverBalances($filter, $limit, $offset)` |
| `CARRYOVER_BALANCE_QUERY` | `carryoverBalanceQueryDocument` | `query CarryoverBalance($id: ID!)` |
| `BULK_CREATE_CARRYOVER_MUTATION` | `bulkCreateCarryoverBalancesMutationDocument` | `mutation BulkCreateCarryoverBalances($input: BulkCreateCarryoverInput!)` |
| `BULK_TO_EXPENSE_MUTATION` | `bulkCarryoverToExpenseMutationDocument` | `mutation BulkCarryoverToExpense($input: BulkToExpenseInput!)` |
| `CREATE_CARRYOVER_MUTATION` | `createCarryoverBalanceMutationDocument` | `mutation CreateCarryoverBalance($input: CreateCarryoverInput!)` |
| `UPDATE_CARRYOVER_MUTATION` | `updateCarryoverBalanceMutationDocument` | `mutation UpdateCarryoverBalance($input: UpdateCarryoverInput!)` |
