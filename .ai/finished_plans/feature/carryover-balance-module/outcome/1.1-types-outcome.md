## Adaptations from the plan (minor, noted)

- **Dropped the unused `CalculationStatus` import** — the plan's §3.1 import block
  includes `CalculationStatus` from `@/backend/enum`, but no listed type body
  references it; importing it would fail lint (unused import). If a later task
  needs it (e.g. an items detail type with `originalStatus` typed), add it there.
- **`CarryoverRow` declared as a plain interface**, not derived from
  `CarryoverBalanceSelectType` — per the plan, which prescribes the explicit
  shape. Derivation would also be awkward since the row intentionally flattens
  `teacherName`/`teacherAvatarUrl` joins and serializes `createdAt`/`paidAt` to
  ISO strings while omitting `createdByUserId`/`paidByUserId`/`updatedAt`.
- **Extracted `CarryoverPaidStatusFilter`** as a named alias for the
  `"Paid" | "Unpaid" | "Both"` union so the GraphQL input type and frontend
  filters can share the literal set instead of repeating it inline.
