### Design notes

- **Expense-adapter observability**: the adapter (`createExpenseRecord`) is
  module-private, so invocations are observed through the stub's single
  `logger.warn` call per record; the failure test spies `logger.warn` to throw,
  which is exactly the adapter's throw path — the service catches it and wraps
  it as `DomainError("CARRYOVER_TO_EXPENSE_FAILED")`.
- **Replay observability**: the audit mock store mimics `queryAuditLogs`'s
  newest-first ordering so the service's `toReversed()` reconstruction returns
  items in original creation order, making first/second results deep-equal.
- `LinkedSessionStub = Pick<ClassInstanceSelectType, "id" | "calculationStatus" | "teacherPaidAmount">`
  keeps the mock session rows typed without the 50-field instance builder; the
  settle flow reads only those three fields.
