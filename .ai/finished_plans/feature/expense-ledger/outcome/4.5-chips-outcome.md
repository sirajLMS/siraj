### ExpenseTypeChip

- Props: `type: ExpenseType` — the **generated GraphQL codegen enum**
  (`@/frontend/common/graphql/generated/gql/graphql`), matching what Apollo rows and
  the existing `expenseFilterStore` already use (avoids forcing grid code to convert
  between the codegen enum and the shared constants enum).
- Labels: `Record<ExpenseType, string>` lookup over `t.type.{Salaries,Marketing,Logistics,Technology}`
  (locale-group keys equal the enum display names); no enum switch statements
  (oxlint `no-unsafe-enum-comparison`).
- Colors (theme-palette container/on-container pairs only, theme-callback `sx`):
  - Salaries (plan: indigo) → `theme.palette.status.completedContainer` /
    `onCompletedContainer` — the violet/indigo hue slot in this theme; the carryover
    `PaidStatusChip` sets precedent for borrowing status families purely for hue.
  - Marketing (amber) → `warningContainer` / `onWarningContainer`.
  - Logistics (blue) → `infoContainer` / `onInfoContainer`.
  - Technology (green) → `successContainer` / `onSuccessContainer`.
- `size="small"` + `aria-label` with the full localized label (screen-reader parity in
  DataGrid cells, per the carryover chips).

### ExpenseSourceChip

- Props: `sourceEntity: string | null`, `sourceEntityId: string | null`, optional
  `onViewSource(sourceEntityId)` — the chip stays a leaf; drawer opening is the
  container's job (§5.6 says click opens `CarryoverDetailDrawer`).
- `sourceEntity === EXPENSE_SOURCE_CARRYOVER_BALANCES` + a non-empty `sourceEntityId`
  → blue clickable chip (`infoContainer`/`onInfoContainer`) with a `LinkOutlined` icon
  (recolored via the `& .MuiChip-icon` slot selector, same trick as
  `DisabledTeacherChip`), matching the prototype's link-glyph source tag. Clicking
  invokes `onViewSource(sourceEntityId)`; without the callback the chip renders
  without a click handler (MUI keeps it non-interactive).
- Otherwise → grey static chip (`surfaceContainerHigh` / `onSurfaceVariant` — the
  exact neutral pair the carryover chips use).
- Both branches: `size="small"` + `aria-label` with the full localized label
  (`t.source.FromCarryover` / `t.source.Manual`).

(`shared/`↔`frontend` layer rules), so per `shared/AGENTS.md` the canonical value is
duplicated into `shared/constants/expenses/`. Added one additive
`export * from "./expense-source.constants"` line to the sibling barrel.

No folder `index.ts` barrel was created (carryover precedent: the container task owns
