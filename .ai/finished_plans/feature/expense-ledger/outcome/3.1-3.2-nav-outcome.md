### 3.2 Sidebar nav item
- **`frontend/common/views/dashboard/config/navigationConfig.ts`** (additive only):
  - Added `AppPermission.AccountingExpensesView` to the `grp_finance` group
    permission array (after `AccountingCarryoverView`).
  - Added a new `SIDEBAR_NAV_ITEMS` entry directly after `accounting-carryover`,
    per plan §6.1, following the sibling convention:
    ```ts
    {
      key: "accounting-expenses",
      labelKey: "accountingExpenses",
      iconKey: "receiptLong",
      href: "/accounting/expenses",
      section: "main",
      permission: PAGE_PERMISSIONS.accountingExpensesView,
      groupId: "grp_finance",
    },
    ```
    Icon `receiptLong` is already used by the billing-invoices items, so it is a
    valid `iconKey` for finance-ledger surfaces.
- **i18n label key `accountingExpenses`** — the sidebar resolves `labelKey`
  against the existing `dashboard.core.nav` namespace
  (`shared/locale/{types,en,ar}/dashboard/core/nav.ts`), not the page namespace.
  Added the key to all three surfaces, positioned between `accountingCarryover`
  and `accountingReports`:
  - Type: `readonly accountingExpenses: string;` in `DashboardNavigationLabels`
  - EN: `"Expense Ledger"`
  - AR: `"سجل المصروفات"` (matches plan §7.1 `title`)
