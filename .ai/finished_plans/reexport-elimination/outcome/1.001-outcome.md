## Collisions Found

### Collision 1: `backend/db/repo/classes/index.ts` — `PendingReviewFilters`

**Files involved:**
- `./lesson-report.repository.ts` — exports `PendingReviewFilters` (interface) and `LessonReportRepository` (class)

**Issue:** Using `export * from "./lesson-report.repository"` alongside `export type { PendingReviewFilters } from "./lesson-report.repository"` causes `TS2308: Module has already exported a member named 'PendingReviewFilters'`. The `export *` picks up `PendingReviewFilters` from the module, colliding with the explicit `export type` statement.

**Resolution:** Kept `export type { PendingReviewFilters } from "./lesson-report.repository"` as-is (rule 3: type-only exports remain type-only). Used `export { LessonReportRepository } from "./lesson-report.repository"` (named export) instead of `export *` for the same file.

**Registry:** Entry 10 in `collisions-registry.md`
