## Analysis

### Files with `export type { }` + separate `export { X }` from same file
- **badge/index.ts**: `export type { MobileStatusBadgeCategory, MobileStatusBadgeProps }` + `export { MobileStatusBadge }` from `./MobileStatusBadge`. Converting the value export to `export *` would also re-export the types, causing `import-x/export` collision. **Kept as-is.**
- **avatar/index.ts**: `export type { BaseAvatarProps, BaseAvatarVariant }` + `export { MobileBaseAvatar }` from `./MobileBaseAvatar`; `export type { ClassAvatarProps }` + `export { MobileClassAvatar }` from `./MobileClassAvatar`. Same collision pattern. **Kept as-is** for these two. However, `export { MobileUserAvatar }` from `./MobileUserAvatar` has NO corresponding `export type { }` in the barrel, so `export *` was safe. **Converted** `MobileUserAvatar` only.
