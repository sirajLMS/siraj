## Files Modified

### 1. `backend/db/seeds/lib/index.ts`
**Violation:** Used named re-exports (`export { A, type B } from "./file"`) instead
of `export * from "./file"`. No collisions exist across the 21 source files (verified
via duplicate export name scan — zero duplicates found).
**Fix:** Converted all 21 named re-export blocks to `export * from "./file"`. All
type exports (e.g., `SeedAssetEntry`, `ScheduleContext`, `SeedConfig`) are now
re-exported via `export *` which handles both values and types.
**Result:**
```ts

export * from "./asset-manifest";
export * from "./audit-factory";
// ... (18 more, total 21 lines)
export * from "./validate-seed-assets";
```
**Note:** 3 lib source files not previously in the barrel
(`currency-catalog-factory.ts`, `meeting-provider-factory.ts`,
`payment-catalog-factory.ts`) are NOT included — they are imported directly by
seeders, not via the barrel. Keeping them out preserves the existing API surface.
