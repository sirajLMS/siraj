## Errors Encountered
1. **Double `type` keyword**: The automated import-splitting script produced `import type { type Foo }` when the original import was `import type { type Foo }` (inline type prefix inside `import type` block). Fixed via `sed -i 's/import type { type /import type { /g; s/, type /, /g'`.
2. **Script missed multi-line `import type` blocks**: The script's grep pattern only matched single-line imports from `@/backend/enum`. Files using multi-line `import type {` blocks were missed and had to be fixed manually (8 files listed above).
3. **`ClassOutcome` used as value**: In `parent.repository.ts`, `ClassOutcome` was imported as `import type` but used as a value (`ClassOutcome.PENDING`). Fixed by switching to `import { ClassOutcome }`.
4. **Inline namespace references**: `profile.types.ts` and `staff-profile.types.ts` used `import("@/backend/enum").CurrencyCode` inline type references. Fixed to use `import("@/shared/constants/currency.enum").CurrencyCode`.
