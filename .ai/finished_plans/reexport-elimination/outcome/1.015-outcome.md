# Batch 015 Outcome — Re-export Elimination

**Date:** 2026-08-12
**Files in batch:** 5

## Summary

All 5 files were `index.ts` barrel files. Four used `@/` paths to same-directory files (violating Rule 6), and one used `./` paths but had named exports that could be converted to `export *`. All files were converted to use `export * from "./file"` with same-directory `./` paths. No collisions, no consumer updates needed.

- `export * from "@/backend/services/notification/notification-preferences.service"`
