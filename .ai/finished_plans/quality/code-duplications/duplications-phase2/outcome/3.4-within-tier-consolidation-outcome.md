## Intentional Duplications (Documented)

### d8 + m6: Teacher Lists Views (classes vs students)
**Decision**: Intentional. While both share the page shell pattern (PageContainer + PageHeader + loading/error/empty states), the row content is fundamentally different domain logic:
- **Classes view**: Renders meeting join buttons, status badges, schedule formatting, class audit actions, view-details links
- **Students view**: Renders simple name + status + quota + hours card

Extracting just the ~14-line page shell would create an over-abstracted wrapper for marginal benefit. The shared pattern is common Next.js page boilerplate, not extractable business logic.

### m7: Recurring Schedule Views (detail vs list)
**Decision**: Intentional. One is a detail page (rate section + meeting configs), the other is a paginated list with search. The shared part is ~6 lines of loading/error state handling — too trivial to extract.
