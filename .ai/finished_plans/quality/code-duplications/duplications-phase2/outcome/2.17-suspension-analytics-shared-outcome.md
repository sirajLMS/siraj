## Tier Config Design

```typescript
export interface SuspensionAnalyticsTierConfig {
  readonly chartPadding: number;
  readonly chartTitleFontFamily: string;
  readonly chartHeight: number;
  // ... 23 more tier-specific properties
  readonly outerContainerSx: SxProps<Theme>;
}
```

Each variant creates a module-level `DESKTOP_TIER` / `MOBILE_TIER` constant object and passes it to the scaffold. The scaffold uses the `tier` prop to apply all tier-specific visual differences. Font family fields use `tier.fontFamily || theme.typography.fontFamily` fallback — empty string triggers theme default.
