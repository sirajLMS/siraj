# Phase 4 Task 4.1b — C↔M Cross-Tier UI Component Extraction — Outcome

## Summary

Resolved 9 C↔M (common ↔ mobile) duplicate pairs. 6 pairs required code changes; 3 pairs were already properly delegating via shared scaffolds and were skipped. All modified files pass `bun run scripts/health/sub-loop.ts <file> --lifecycle codescene` (tsgo → oxlint → biome → lint:type-aware → check:duplicates → codescene).

## Pair Results

### 1. BaseCard (224t) — ✅ Fixed
- **Common**: `frontend/common/components/ui/card/BaseCard.tsx` (unchanged — shared base)
- **Mobile**: `frontend/mobile/components/ui/card/BaseCard.tsx` — replaced full duplicate with re-export from common
- **Action**: Mobile `BaseCard.tsx` now re-exports `BaseCard` and `BaseCardProps` from common. The actual mobile-tuned card (`MobileBaseCard.tsx`) is untouched — it has intentional differences (edgeToEdge=true default, scale animation).

### 2. HorizontalScrollRow (79t) — ✅ Fixed
- **Common**: `frontend/common/components/ui/container/HorizontalScrollRow.tsx` (unchanged — shared base)
- **Mobile**: `frontend/mobile/components/ui/container/MobileHorizontalScrollRow.tsx` — replaced full duplicate with delegation
- **Action**: Mobile now delegates to common `HorizontalScrollRow`. The mobile variant restricts `showScrollbar` to `boolean` (never the `"desktop"` breakpoint mode the common component offers). Default `showScrollbar=false` preserved.

### 3. LocalizedStringDisplay (106t) — ✅ Fixed
- **Common**: `frontend/common/components/ui/display/localizedStringDisplay/LocalizedStringDisplay.tsx` (unchanged — shared base)
- **Mobile**: `frontend/mobile/components/ui/display/localizedStringDisplay/localizedStringDisplay.mobile.tsx` — replaced full duplicate with delegation
- **Action**: Mobile now delegates to common `LocalizedStringDisplay`, defaulting `typographyVariant="caption"` for compact mobile typography. Uses `UiTypographyVariant` type from `shared.types.ts` (same type both tiers used).

### 4. AppDateRangePicker (101t) — ⏭️ Skipped (already delegating)
- **Common**: `frontend/common/components/ui/form/date/AppDateRangePicker.tsx`
- **Mobile**: `frontend/mobile/components/ui/form/date/MobileAppDateRangePicker.tsx`
- **Reason**: Both already delegate to shared `DateRangePickerChrome` scaffold. Mobile uses `MobileAppDatePicker` + `container="drawer"`; common uses `AppDatePicker` + `container="popover"`. Different slot components — already properly separated.

### 5. AppTimeRangePicker (94t) — ⏭️ Skipped (already delegating)
- **Common**: `frontend/common/components/ui/form/time/AppTimeRangePicker.tsx`
- **Mobile**: `frontend/mobile/components/ui/form/time/MobileAppTimeRangePicker.tsx`
- **Reason**: Both already delegate to shared `TimeRangePickerChrome` scaffold. Mobile uses `MobileAppTimePicker` + `container="drawer"`; common uses `AppTimePicker` + `container="popover"`. Different slot components — already properly separated.

### 6. PhoneFormField (106t) — ✅ Fixed
- **Common**: `frontend/common/components/ui/input/phoneInput/PhoneFormField.tsx` — now delegates to `PhoneFormFieldShared`
- **Mobile**: `frontend/mobile/components/ui/input/phoneInput/phoneFormField.mobile.tsx` — now delegates to `PhoneFormFieldShared`
- **New shared**: `frontend/common/components/ui/input/phoneInput/PhoneFormFieldShared.tsx`
- **Action**: Extracted the Controller + render logic to a shared scaffold that accepts a `PhoneInputComponent` prop. Both common and mobile `PhoneFormField` variants pass their tier-specific `PhoneInput` component. The duplicate Controller/render structure is eliminated.

### 7. PhoneInput (118t) — ⏭️ Skipped (already delegating)
- **Common**: `frontend/common/components/ui/input/phoneInput/PhoneInput.tsx`
- **Mobile**: `frontend/mobile/components/ui/input/phoneInput/PhoneInput.tsx`
- **Reason**: Both already delegate to `PhoneInputShared` with different slot components (mobile uses `MobileLocaleEmoji` + `PhoneCountryPickerMobile` + `useOnNationalInput=false`; common uses `LocaleEmoji` + `PhoneCountryPicker`). Already thin wrappers — no further delegation needed.

### 8. Search Bars (99t) — ✅ Fixed
- **Common**: `frontend/common/views/dashboard/settings/components/timezones/SettingsTimezonesSearchBar.tsx` — now delegates to `SearchBarField`
- **Mobile**: `frontend/mobile/views/dashboard/billing/components/billingMobileSearchBar.mobile.tsx` — now delegates to `SearchBarField`
- **New shared**: `frontend/common/components/ui/input/searchBarField/SearchBarField.tsx`
- **Action**: Extracted the shared TextField + SearchOutlined + InputAdornment pattern to `SearchBarField`. Both wrappers supply their own outer `Box` layout and delegate the input to the shared component.

### 9. Card Lists (112t) — ✅ Fixed
- **Common**: `frontend/common/views/dashboard/supervisor/dashboard/components/RecentApprovalCardList.tsx` — now imports `StyledTimeHighlight` from shared
- **Mobile**: `frontend/mobile/views/dashboard/teachers/dashboard/components/teacherScheduleMobileCard.mobile.tsx` — now imports `StyledTimeHighlight` from shared
- **New shared**: `frontend/common/views/dashboard/components/__shared__/timeHighlightShared.styles.ts`
- **Action**: Extracted the identical `StyledTimeHighlight` styled component (alpha-primary tinted background/border) to a shared styles file. Both components import it instead of defining their own copy. The components themselves are very different (different card structures, different data, different actions) — only the `StyledTimeHighlight` was duplicated. Also removed unused `alpha` import from mobile file.
