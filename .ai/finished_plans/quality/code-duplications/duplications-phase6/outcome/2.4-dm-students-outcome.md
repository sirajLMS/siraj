## Key Decisions

- **Slot pattern**: Components that differ between tiers (`Panel`, `Autocomplete`, `SectionPanel`, `StatusBadge`, `PrimaryPageAction`) are passed as `ComponentType<T>` slots via options objects, not imported in the common scaffold.
- **No options files**: Options are inlined as `const DESKTOP_OPTIONS` / `const MOBILE_OPTIONS` in wrapper files rather than separate `.options.ts` files, since they reference tier-specific components.
- **Private utilities**: Functions like `getBadgeStatusKey` and `STATUS_BADGE_MAP` are kept private (not exported) in scaffold files to avoid `react-refresh/only-export-components` warnings.
- **Layout differences**: Page-level layout (containers, headers, status banners) that differs structurally between tiers stays in wrapper files. Only the form body / shared content is extracted.
- **Existing scaffolds**: `studentQuotaShared.tsx` was already created in a prior session. This session only extracted the `wrapContextualHelperCardsDefault` utility to eliminate the remaining clone.
