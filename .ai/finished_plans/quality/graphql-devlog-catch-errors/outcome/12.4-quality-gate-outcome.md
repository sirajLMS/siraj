## Carry-Forward Knowledge

- `bun:test` does NOT support `{ skip: true }` as options object — use `test.skip` method via `testMaybe` pattern
- If ALL tests in a file use `test.skip`, add at least one non-skipped test to satisfy `sonarjs/no-empty-test-file`
- CodeScene flags repeated test assertion patterns — extract helper functions with generics to deduplicate
- Helper function generics: use `<TVars extends Record<string, unknown>>` with `TypedDocumentNode<unknown, TVars>` for type-safe test helpers
