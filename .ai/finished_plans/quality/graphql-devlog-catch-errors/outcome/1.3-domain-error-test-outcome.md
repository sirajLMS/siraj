## Carry-Forward Knowledge

- `ValidationError` has overloaded constructor: `(message)` → code `VALIDATION`, or `(code, message)` → custom code. This is used by recurring-class validation (Task 4) for `RECURRING_CLASS_DAYS_REQUIRED`, `INVALID_DURATION`, `SUBJECT_REQUIRED`.
- `NotFoundError(entity, message)` auto-generates code as `${entity}_NOT_FOUND`. Callers must pass the entity name (e.g., `"SUGGESTION"`, `"COMPLAINTS"`), NOT the full code.
- `QuotaNotFoundError` extends `NotFoundError` with entity `"QUOTA"` → code `QUOTA_NOT_FOUND`.
