## Key Learning

When a source file has both type and value exports, `export *` alone is sufficient (it re-exports both types and values). Having both `export type { X } from "./file"` AND `export * from "./file"` for the same file causes ESLint `import-x/export` "Multiple exports" errors. The correct pattern is to drop the explicit `export type { }` line and keep only `export *`.
