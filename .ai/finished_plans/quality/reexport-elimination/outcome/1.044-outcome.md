# Batch 044 — Re-export Elimination Outcome

## Files Modified

### 1. `frontend/desktop/components/ui/form/index.ts`
- **Before:** 4 `export *` statements with `@/` cross-directory paths (`@/frontend/desktop/components/ui/form/date`, etc.)
- **After:** Converted to `./` same-directory paths (`./date`, `./field`, `./snackbar`, `./time`)
- **Rule:** Rule 1/6/7 — index.ts may only export from same-directory files using `./` paths

### 2. `frontend/desktop/components/ui/form/snackbar/DesktopFormSuccessSnackbar.tsx`
- **Before:** `export { FormSuccessSnackbar as DesktopFormSuccessSnackbar } from "@/frontend/common/..."` (cross-dir re-export inline in component file)
- **After:** Converted to `import { FormSuccessSnackbar } from "@/frontend/common/..."` + `export { FormSuccessSnackbar as DesktopFormSuccessSnackbar }` (import then re-export, no inline cross-dir re-export)
- **Rule:** Rule 3a — non-index file with re-export: remove inline re-export, use import + local export

### 3. `frontend/desktop/components/ui/form/time/index.ts`
- **Status:** Already compliant (uses `./` paths, `export type { }` kept as-is per rule 3, named `export { }` kept due to collision)
- **Collision:** `export * from "./DesktopAppTimePicker"` causes `import-x/export` collision with `export type { DesktopAppTimePickerProps }` — both export the type. Same for `DesktopAppTimeRangePicker`.
- **Registry:** Entry 32 in `collisions-registry.md`

### 4. `frontend/desktop/components/ui/index.ts`
- **Before:** `export { DesktopAppDataGrid, type DesktopAppDataGridProps } from "./dataGrid/DesktopAppDataGrid"` + individual exports for overlays
- **After:** Replaced with `export * from "./dataGrid"` (dataGrid/index.ts already `export *` from all 3 files)
- **Rule:** Rule 2 — convert `export { }` to `export *` when no collision

### 5. `frontend/desktop/components/ui/input/catalogImageUpload/index.ts`
- **Status:** Already compliant (uses `./` paths, `export type { }` kept as-is per rule 3, named `export { }` kept due to collision)
- **Collision:** `export * from "./catalogImageUpload.desktop"` causes `import-x/export` collision with `export type { CatalogImageUploadProps }` — both export the type.
- **Registry:** Entry 33 in `collisions-registry.md`

- `frontend/desktop/components/ui/input/catalogImageUpload/index.ts` — uses `./` paths only, collision prevents `export *` conversion
