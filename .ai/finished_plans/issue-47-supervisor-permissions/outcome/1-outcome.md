# Phase 1 Outcome: Database Migrations — Grant Permissions

## Summary

Three migration SQL files were edited in-place to grant supervisors full teacher/student management permissions and academy_admin (manager) role ACL customization permissions.

## Files Modified

1. **`backend/db/migration/6-lms-permissions-and-groups.sql`** (Task 1.1)
   - Added comment block above `supervisor_default` INSERT documenting that supervisors get ALL teacher/student management permissions
   - Appended 8 non-field-ACL permissions to `p.key IN (...)` clause:
     - `teachers.create`, `teachers.edit`, `teachers.manage_schedule`
     - `students.create`, `students.edit`
     - `student.reassign_teacher`, `student.manage_status`
     - `staff.view_directory`
   - Uses `ON CONFLICT DO NOTHING` — idempotent

2. **`backend/db/migration/6d-profile-fine-grained-only.sql`** (Task 1.2)
   - Appended 21 `edit_other` field-ACL permissions to `supervisor_default` `p.key IN (...)` clause
   - Covers: core_identity, core_contact, teacher_professional, teacher_identity, parent_social, parent_identity, parent_billing, parent_account, parent_students, teacher_students, staff_role, staff_permissions, payment_methods, meeting_configs, student_identity, student_academic, student_teacher, student_parent, student_schedule, student_history, student_quota_edit
   - Deliberately excludes `profile.core_status.edit_other` (supervisor lacks `view_other` for `core_status`)
   - Uses `ON CONFLICT DO NOTHING` — idempotent

3. **`backend/db/migration/3-system_permissions_and_groups.sql`** (Task 1.3)
   - Appended 7 permissions to `academy_admin` `p.key IN (...)` clause:
     - `permission_groups.manage`, `permission_groups.assign`
     - `teachers.edit`, `teachers.list`
     - `students.edit`, `students.change_teacher`, `students.change_status`
   - Uses `ON CONFLICT DO NOTHING` — idempotent

## Files NOT Modified
- No Drizzle mirror folders manually edited (auto-generated by `bun db migrate`)
- No schema files changed (migrations are pure SQL)

## Verification
- Quality loop (sub-loop.ts) passed on all 3 files
- In-place edits with `ON CONFLICT DO NOTHING` ensure idempotency
