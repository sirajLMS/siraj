## Scaffold Architecture

The scaffold contains ALL previously duplicated logic:
- **Sub-components**: `TeacherSelection` (accepts `TeacherAutocomplete` slot), `StatusUpdate` (accepts `StatusBadge` slot), `ActionButtons` (no slots — identical across tiers)
- **Main component**: `ManagementControlsCardShared` — destructures shared props + slots, renders `CardContainer` with title/subtitle header, teacher selection, status update, and action buttons

### Slot Prop Type Contracts

- **`SharedCardContainerProps`**: `{ sx?: SxProps<Theme>, children: ReactNode }` — matches both `BaseCard` and `MobileBaseCard` which extend `CardProps`
- **`SharedStatusBadgeProps`**: `{ category: "studentAccount", status: string, label: string }` — matches both `DesktopStatusBadge` and `MobileStatusBadge` props
- **`SharedTeacherAutocompleteProps`**: `{ value: PersonOption | null, onChange: (next: PersonOption | null) => void, label: string, placeholder: string }` — matches `TeacherAutocompleteProps` subset used by both tier variants
