### Problem
`heroSummaryCardShared.tsx` (common/desktop) and `supervisorHeroCardShared.tsx` (mobile) duplicated 89 tokens of hero summary card JSX structure. The mobile fork used a different action button component, smaller icon, and different border/padding styles.

### Solution
1. **Extended common `heroSummaryCardShared.tsx`** with:

2. **Extracted `MOBILE_HERO_CARD_SX`** to `heroCardSx.constants.ts` (separate file to avoid `react-refresh/only-export-components` warning — `.tsx` with `"use client"` can't mix component and constant exports)
3. **Deleted mobile fork** `supervisorHeroCardShared.tsx`
4. **Updated 4 consumers**:
   - Desktop: `pendingReviewsHeroCard.desktop.tsx`, `duesSummaryCard.desktop.tsx` → pass `DesktopPrimaryPageAction` slot
   - Mobile: `pendingReviewsHeroCard.mobile.tsx`, `duesSummaryCard.mobile.tsx` → import `HeroSummaryCardShared` from common + `MOBILE_HERO_CARD_SX` from constants, pass `MobilePrimaryPageAction` slot + mobile-specific `iconCircleSize=40`, `stackGap=1.5`, `titleSubtitleGap=0.5`
