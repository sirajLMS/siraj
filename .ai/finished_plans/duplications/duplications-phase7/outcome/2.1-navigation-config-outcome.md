# Task 2.1 — navigationConfig.ts Within-File Clones

## What was found

`frontend/common/views/dashboard/config/navigationConfig.ts` had two within-file clone pairs between `SIDEBAR_NAV_ITEMS` and `BOTTOM_NAV_ITEMS`:

1. **Teacher nav items** (342 tokens): `today-classes`, `regular-schedule`, `your-students` — identical in both arrays.
2. **Student/supervisor nav items**: `student-today-classes`, `student-schedule`, `student-sessions`, `student-credits`, `supervisor-home`, `pending-reviews`, `teacher-dues` — identical except `teacher-dues` has `groupId: "grp_finance"` in sidebar but omits it in bottom nav (bottom nav ignores groups).

## What was done

- Extracted `makeTeacherNavItems()` factory at module scope — returns the 3 teacher NavItem objects.
- Extracted `makeStudentSupervisorNavItems(includeGroupId: boolean)` factory at module scope — returns the 7 student/supervisor NavItem objects. The `teacher-dues` entry conditionally includes `groupId` based on the parameter.
- `SIDEBAR_NAV_ITEMS` now uses `...makeTeacherNavItems()` and `...makeStudentSupervisorNavItems(true)`.
- `BOTTOM_NAV_ITEMS` now uses `...makeTeacherNavItems()` and `...makeStudentSupervisorNavItems(false)`.
