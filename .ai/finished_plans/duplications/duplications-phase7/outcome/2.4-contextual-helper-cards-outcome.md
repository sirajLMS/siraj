# Task 2.4 — contextualHelperCards.mobile.tsx Within-File Clones

## What was found

`frontend/mobile/views/dashboard/students/quota/components/contextualHelperCards.mobile.tsx` had a within-file clone: two nearly identical helper card Box sections that rendered an icon, title, and description with the same layout but different colors and content.

## What was done

- Extracted `ContextualHelperCard` local presentational component at module scope with props: `icon`, `title`, `description`, `titleColorKey` ("primary"|"onSurface"), `backgroundColorKey` ("surfaceVariant"|"surfaceContainerLow").
- Extracted `resolveTitleColor` and `resolveBackgroundColor` helper functions at module scope to safely resolve MUI palette values to strings (avoids tsgo error from dynamic palette key access returning `PaletteColor` union).
- Both helper card sections now render `<ContextualHelperCard .../>` with different props.
