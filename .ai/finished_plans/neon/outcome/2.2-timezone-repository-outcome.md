## Changes Made

### Added module-level prepared statements (Drizzle Prepared Statements 2.0)

1. **`listAllPrepared`** (`list_all_timezones`)
   - `db.select().from(timezones).prepare("list_all_timezones")`
   - Simple select-all query, no parameters

2. **`findByIanaIdsPrepared`** (`find_timezones_by_iana_ids`)
   - `db.select().from(timezones).where(inArray(timezones.ianaId, sql.placeholder("ianaIds")))` 
   - Batch lookup by ianaId array using `sql.placeholder("ianaIds")`

### Refactored Repository Methods

- **`listAll(tx?)`**: Uses `listAllPrepared.execute()` when no transaction, falls back to `tx.select().from(timezones)` when `tx` is provided
- **`findByIanaIds(ianaIds, tx?)`**: Uses `findByIanaIdsPrepared.execute({ ianaIds })` when no transaction, falls back to regular query with `tx` when provided
- **`upsertMany`**: Left unchanged (write operation, excluded per rollout policy)
