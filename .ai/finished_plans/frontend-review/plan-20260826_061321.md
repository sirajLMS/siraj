# Frontend Refactoring Plan

## MUI v9 & React 19 Migration Fixes

### FIX-1 (CRITICAL): Render-phase `setState` in `useLoginViewModel`

**File:** `frontend/views/auth/login/useLoginViewModel.ts:92-113`

**Before:**
```ts
const [prevAuthError, setPrevAuthError] = useState<string | null>(null);
...
if (authError !== prevAuthError) {
  setPrevAuthError(authError);
  if (authError) {
    setLoginResult({ type: "error", message: authError });
  }
}
```

**After:**
```ts
useEffect(() => {
  if (authError) {
    setLoginResult({ type: "error", message: authError });
  }
}, [authError]);
```
Delete `prevAuthError` + `setPrevAuthError` entirely. This also removes the extra render pass.
