UX Specification: Tab - Permission Catalog

Layout

Description: Read-only view of all available system permissions.

Top Bar:

Left: Search input ("Search permissions...")

Left (adjacent): Category Filter Dropdown (e.g., "All Categories", "Users", "Billing", "Content").

Content: PaginatedDataGrid

Columns

Permission Key: e.g., users.create (Monospace font).

Category: e.g., User Management.

Description: Plain text explanation of the permission.

Used In: Comma-separated list of Group Names that currently utilize this permission.
