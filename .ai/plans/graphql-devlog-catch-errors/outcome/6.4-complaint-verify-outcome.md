# Task 6.4 — Complaint three-layer verification

## Summary
Verified all three-layer tests pass for COMPLAINTS_NOT_FOUND code propagation. Fixed a bug in `complaintResponses.service.ts` where `assertCanRespondToComplaint` threw plain `Error` instead of `NotFoundError`/`UnauthorizedError`.

## Bug Found & Fixed
- **File**: `backend/services/communication/complaintResponses.service.ts`
- **Bug**: `assertCanRespondToComplaint` used `throw new Error(tErrors.complaintNotFound)` (line 27) and `throw new Error(tErrors.insufficientPermissions)` (line 22)
- **Impact**: `respondToComplaint` mutation returned `INTERNAL_SERVER_ERROR` instead of `COMPLAINTS_NOT_FOUND` for non-existent complaints
- **Fix**: 
  - Imported `NotFoundError` and `UnauthorizedError` from `@/backend/lib/errors`
  - Changed permission check to `throw new UnauthorizedError(tErrors.insufficientPermissions)`
  - Changed not-found check to `throw new NotFoundError("COMPLAINTS", tErrors.complaintNotFound)`
