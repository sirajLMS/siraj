# Task 3.2 Outcome: teachers GraphQL Domain — `displayAmount` N+1 Fix

**Date:** 2026-07-31  
**Task:** 3.2 teachers Domain (`displayAmount` on `TeacherOwnProfile`)  
**Status:** ✅ Completed

---

## Summary

Eliminated an N+1 query pattern in the `teachers` GraphQL domain by moving the `displayAmount` field resolution from the per-parent Pothos field resolver into the service layer. The field is now pre-computed in `TeacherPortalService.getOwnProfile()` and exposed directly via `t.expose()`, removing the per-profile `FxDisplayService.convertForDisplay()` call from the GraphQL field resolver.

---

## Changes Made

### 1. Modified Files

#### `backend/types/teachers/teacher.types.ts`
- Added `displayAmount: DisplayAmountReturnType | null` to `TeacherOwnProfileReturnType`

#### `backend/services/teacher/teacher-portal.service.ts`
- Added `import { CurrencyCode }` and `import { FxDisplayService }` imports
- Changed `getOwnProfile()` signature to accept `displayCurrency?: CurrencyCode | null, locale?: string`
- After fetching the profile, computes `displayAmount` via `FxDisplayService.convertForDisplay()` and includes it in the return object
- Updated `updateOwnProfile()`'s call to `getOwnProfile()` with `undefined, undefined` for backwards compatibility

#### `backend/graphql/query/teachers/teacher-portal.query.ts`
- Updated `teacherOwnProfile` resolver to pass `ctx.user?.displayCurrency` and `ctx.locale` to `getOwnProfile()`

#### `backend/graphql/pothos/teachers/teacher-portal.pothos.ts`
- Removed `resolveDisplayAmountField` import
- Changed `displayAmount` from `t.field({ ... resolve: (parent, _args, ctx) => ... })` to `t.expose("displayAmount", { type: DisplayAmountPothosObject, nullable: true })`

---

## N+1 Reduction

| Field | Before | After |
|---|---|---|
| `displayAmount` on `TeacherOwnProfile` | N calls to `FxDisplayService.convertForDisplay()` (one per profile) | 0 field resolvers — pre-computed once in service layer |

**Before (N+1):** For N teacher profiles queried in a list, `displayAmount` triggers N separate `FxDisplayService.convertForDisplay()` calls from the per-parent field resolver.  
**After (pre-computed):** `displayAmount` is computed once during `getOwnProfile()` and exposed as a simple property — no per-field resolution cost.
