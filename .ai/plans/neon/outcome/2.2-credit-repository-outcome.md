## Pattern Followed

Exactly matching the pilot pattern from `backend/db/repo/users/user.repository.ts`:
1. Prepared statement defined at **module level** (before the namespace)
2. `sql.placeholder("keys")` for the dynamic array parameter
3. `.prepare("find_credit_tx_by_idempotency_keys")` with a unique descriptive name
4. `.execute({ keys: [...keys] })` at call site
5. Transaction fallback: when `tx` is provided, skip the prepared statement and use the regular query builder
