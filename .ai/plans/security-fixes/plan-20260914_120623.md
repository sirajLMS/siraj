## HIGH Severity

### H1 — Session Invalidation on Password Change & Admin Reset
**File:** `backend/services/auth/auth-password.service.ts` (~lines 30–95)
**Layer:** Service (Auth)
**Problem:** `changePassword` and `adminResetPassword` call `UserRepository.updatePassword` without revoking the target's sessions or refresh tokens; an attacker who captured a session cookie retains access indefinitely after credential rotation.

**Fix — Exact change:**
```ts
// backend/services/auth/auth-password.service.ts
import { SessionRepository } from "@/backend/db/repo/shared";

// inside AuthPasswordService.changePassword, AFTER updatePassword succeeds:
await SessionRepository.deleteByUserId(userId);

// inside AuthPasswordService.adminResetPassword, AFTER updatePassword succeeds:
await SessionRepository.deleteByUserId(targetUserId);
```
And in `backend/graphql/mutation/auth/auth.mutation.ts` (changePassword resolver), after the service call returns true, call `clearAuthCookies(ctx.cookies)` so the actor's own rotated session must re-auth, i.e.:

```ts
resolve: async (_p, args, ctx) => {
  await requireAuthWithRateLimit(ctx).then(({ userId }) =>
    AuthPasswordService.changePassword(userId, args.input, ctx.locale)
  );
  clearAuthCookies(ctx.cookies);
  return true;
}
```

- [ ] H1.QL — `bun run scripts/health/sub-loop.ts backend/services/auth/auth-password.service.ts --lifecycle codescene`
- [ ] H1.QL — same for `backend/graphql/mutation/auth/auth.mutation.ts`
- [ ] H1.TE — 4 tiers: statement (update→delete called), boundary (zero sessions to delete → no throw), chaos (concurrent session exists in Redis + PG), security (reset as admin → old access token must 401 on next request)
- [ ] H1.SEC — replay old session after reset; confirm BOLA impossible (already-deleted sessions 2nd reset no-op)
- [ ] H1.SR — no silent swallow of deleteByUserId errors; propagate or `logger.error` and rethrow
- [ ] H1.IV — verify changes respect codebase patterns (tx plumbing, error i18n)

### H2 — Explicit kill-switch for test-helper mutations
**File:** `backend/lib/test-helper-gate.ts` (~lines 5–25) + `backend/graphql/mutation/shared/test-helper.mutation.ts`
**Layer:** Lib gating + GraphQL registration
**Problem:** Mutations register when `NODE_ENV !== "production"` even without TEST_SERVER/TEST_CI — a misconfigured network-exposed deploy gets `ensureDemoUsers`, `createTestEntities`, `createTestSuperAdmin` for any logged-in user.

**Fix:**
```ts
// backend/lib/test-helper-gate.ts
export function isTestHelperEnabled(): boolean {
  if (isRealProductionDeployment()) return false;
  // HARD requirement — never fall back to NODE_ENV inference for a write-capable surface
  return process.env.TEST_SERVER === "1" || isTestCi();
}
```
And in `test-helper.mutation.ts`, wrap all registrations with `assertTestHelperAllowed()` already present — kept, but also ensure GraphQL registration guard throws loudly in prod:
```ts
if (isTestHelperEnabled()) { /* existing registrations */ }
else if (process.env.NODE_ENV !== "production") {
  logger.warn("test-helper mutations NOT registered: TEST_SERVER!=1 and TEST_CI!=true");
}
```

### H3 — Public-path bypass in file serving
**File:** `app/api/storage/files/[[...path]]/route.ts` + `backend/services/storage/storage.service.ts`
**Layer:** API Route + Service
**Problem:** `if (relativePath.startsWith("public/"))` short-circuits auth *before* any access check; test bootstrap seeds `public/invoices`; uploads/attachments that ever land under `public/` are anonymously retrievable.

**Fix (defense-in-depth):**
```ts
// storage.service.ts — hard guard at every writer
export function assertNonPublicPath(path: string, tErrors: ErrorsLabels): void {
  if (path.startsWith("public/") || path === "public") {
    logger.warn("Blocked write into public namespace", { path });
    throw new ForbiddenError(tErrors.file.invalidFilePath);
  }
}
// call assertNonPublicPath in: StorageDbRepository.createFile (for
// usage-linked records), linkFileToParent, linkFileToInvoice,
// registerFileUsage, and performJunctionInsert.
```
And migrate test bootstrap (`backend/services/system/test-helper.service.ts`) to use `test-data/docs/…` instead of `public/docs`/`public/invoices`.

### H4 — Teacher search endpoint bulk exposure
**File:** `backend/services/teacher/teacher.service.ts` + `backend/graphql/query/teachers/teacher.query.ts`
**Layer:** Service + Resolver
**Problem:** `teachers(search, limit)` is `loggedIn`-only; the service only checks non-null userId. Parents can enumerate full staff roster.

**Fix:**
```ts
// teacher.service.ts
export async function searchTeachers(userId, search, limit, locale) {
  const tErrors = getServerTranslations(locale ?? "ar").errorsTranslations;
  if (!userId) throw new Error(tErrors.unauthorized);
  const ctx = await PermissionsService.getUserContext(userId);
  const allowed =
    ctx.isSuperAdmin ||
    [AppPermission.TEACHERS_LIST, AppPermission.STAFF_VIEW_DIRECTORY, AppPermission.SUPERVISOR_VIEW_DASHBOARD]
      .some(p => ctx.permissions.includes(p));
  if (!allowed) throw new ForbiddenError(tErrors.insufficientPermissions);
  return TeacherRepository.searchTeachers(search, limit);
}
```

### M1 — IPv6 rate-limit bucket collapse
**File:** `backend/lib/ip-utils.ts`
**Fix (replace naive colon split):**
```ts
export function sanitizeIpAddress(ip: string | null | undefined): string | null {
  if (!ip) return null;
  let candidate = ip.trim();
  // bracketed IPv6 with optional port
  const bracketed = /^\[([^\]]+)\](:\d+)?$/.exec(candidate);
  if (bracketed) candidate = bracketed[1];
  // full IPv6
  if (isIP(candidate) === 6) return candidate;
  // IPv4 with port
  const v4 = /^(\d{1,3}(?:\.\d{1,3}){3})(?[IP_REDACTED]\d+)?$/.exec(candidate);
  if (v4 && isIP(v4[1]) === 4) return v4[1];
  if (isIP(candidate) === 4) return candidate;
  return "[IP_REDACTED]";
}
```
