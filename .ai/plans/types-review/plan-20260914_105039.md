# Type System Refactoring Plan

## Non-Negotiable Execution Protocol

Every file modified by this plan MUST be verified immediately after edit via the per-file progressive loop:

```bash
bun run scripts/health/sub-loop.ts <file-path> --lifecycle codescene
```

This executes `tsgo → oxlint → biome:check → lint:type-aware → check:duplicates → codescene --file` in strict order, short-circuiting at the first failure. Exit code 0 is mandatory before moving to the next file. Every task below carries the mandatory 5-subtask breakdown: **QL** (per-file quality loop), **TE** (test engineering via tsgo + type regression tests), **SEC** (security/tenancy review — no sensitive field exposure through new types), **SR** (semantic review gate), **IV** (instruction verification against discovered AGENTS.md and `.agents/instructions/backend.instructions.md`).
