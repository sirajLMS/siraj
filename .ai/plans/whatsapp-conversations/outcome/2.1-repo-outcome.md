## Method signatures (carry-forward for task 2.4 service)

All return `WhatsappTestRecipientReturnType` (status re-typed to
`WhatsappTestRecipientStatus`; out-of-enum values narrow back to `PENDING`).

```ts
listByAccountId(accountId: string, tx?): Promise<WhatsappTestRecipientReturnType[]>
  // oldest-first (createdAt, id)
findByAccountAndPhone(accountId: string, phoneNumber: string, tx?): Promise<WhatsappTestRecipientReturnType | null>
countByAccountId(accountId: string, tx?): Promise<number>
create(input: { accountId; phoneNumber; note?; createdByUserId }, tx?): Promise<WhatsappTestRecipientReturnType>
  // duplicate (accountId, phoneNumber) throws the driver unique violation —
  // the service translates it into a domain error
deleteById(id: string, tx?): Promise<WhatsappTestRecipientReturnType | null>
  // hard delete; null when id unknown
recordVerify(id, { allowed, errorCode, checkedAt }: { allowed: boolean; errorCode: string | null; checkedAt: Date }, tx?)
  : Promise<WhatsappTestRecipientReturnType | null>
  // allowed=true → ALLOWED (lastErrorCode/checkpoint stored); false → PENDING;
  // null when id unknown
```

Types come from the task-1.4 additions: `WhatsappTestRecipientSelectType` /
`InsertType` / `ReturnType` in `backend/types/whatsapp/whatsapp-conversations.types.ts`,
`WhatsappTestRecipientStatus` from `@/backend/enum/whatsapp`.
