## Final key names (EXACT — services/GraphQL must reference these)

Note: design-05 spelled the codes as dotted `whatsapp.*` names. The `errors` namespace
uses flat camelCase keys on the top-level `ErrorsLabels` interface (existing style, e.g.
`whatsappAccountNotFound`, `whatsappConnectionTestFailed`), so the dotted design names were
mapped accordingly. Design names that differ from the task brief are reconciled below.

| design-05 / brief spelling | FINAL key in `errors` namespace | Meaning |
|---|---|---|
| `whatsapp.recipientNotAllowed` | `whatsappRecipientNotAllowed` | Test number may only message Meta-dashboard-approved recipients (local pre-send block) |
| `whatsapp.recipientNotAllowedMetaHint` / `whatsapp.recipientNotAllowedFromMeta` | `whatsappRecipientNotAllowedFromMeta` | Meta rejected mid-send with 131030 ("not in allowed list") |
| `whatsapp.outsideServiceWindow` | `whatsappOutsideServiceWindow` | Free-text reply outside the 24-hour customer-service window |
| `whatsapp.sendFailed` / `whatsapp.conversationSendFailed` | `whatsappConversationSendFailed` | Generic send failure |
| `whatsapp.recipientLimitReached` | `whatsappRecipientLimitReached` | Test numbers support at most 5 recipients |
| `whatsapp.recipientConflict` | `whatsappRecipientConflict` | Duplicate `(accountId, phoneNumber)` recipient registration |
| `whatsapp.templateRequired` | `whatsappTemplateRequired` | Template required to open a conversation outside the window |
| `whatsapp.messageRequired` | `whatsappMessageRequired` | Empty message body |

All 8 are **plain strings** (no interpolation/pluralization), matching the surrounding
whatsapp entries. Resolve via `ctx.t("errors", ...)` / `tErrors` per the existing
DomainError → GraphQL `extensions.code` pattern (see
`docs/graphql/domain-error-extensions-code.md`).

## English strings (verbatim)

- `whatsappRecipientNotAllowed`: "This number is a Meta test number and can only message
  recipients approved in your Meta App Dashboard. Add and verify the recipient first."
- `whatsappRecipientNotAllowedFromMeta`: "Meta rejected the recipient: the number is not in
  the test number's allowed list. Open Meta App Dashboard to approve it, then try again."
- `whatsappOutsideServiceWindow`: "Free-text replies are only allowed within 24 hours of the
  customer's last message. Send a template message instead."
- `whatsappConversationSendFailed`: "The message could not be sent. Please verify the
  recipient and connectivity and try again."
- `whatsappRecipientLimitReached`: "Meta test numbers support at most 5 recipients. Remove
  one before adding another."
- `whatsappRecipientConflict`: "This recipient is already registered for this WhatsApp number."
- `whatsappTemplateRequired`: "Select a template to start a conversation outside the
  24-hour window."
- `whatsappMessageRequired`: "Enter a message to send."
