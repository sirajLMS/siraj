# Task 5.9 — MeetingIntegrationsHealthHeaders Component

## What was done

Built the `MeetingIntegrationsHealthHeaders` component displaying four metric cards summarizing the health of meeting integrations, using MUI Grid and Card components per Material 3 patterns.

## Files created

- `frontend/common/views/dashboard/settings/components/meetingIntegrations/MeetingIntegrationsHealthHeaders.tsx` — health summary component with four metric cards:
  - **Providers Configured** — count of meeting integration providers registered in the system
  - **Credentials Healthy** — count of providers with healthy credentials
  - **Teachers Connected** — total count of connected teacher accounts across all providers
  - **Reauth Needed** — count of connected accounts in `reauth_needed` or `expiring_soon` status

  Uses MUI `Grid` + `Card` components following Material 3 patterns (no hardcoded colors — all values sourced from theme palette via `sx` prop callbacks).
