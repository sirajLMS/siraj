## Notes
- The weekly schedule query uses Apollo Client v4 stateful `useQuery` with `skip` — no `useLazyQuery`, per project convention.
- `bookingsInstances` is a `Map` keyed by `meetingConfigId` to avoid re-fetching an already-loaded bookings list on expand/toggle.
- `ViewBookingsLink` is a plain UI affordance (icon + label); the expand/collapse state is owned by the view model via `expandedBookingsId`.
- `LinkedClassInstancesList` is conditionally rendered only for the currently-expanded config row to keep the DOM light.
- `handleReconnect` is wired to the `ReauthNeededBanner`'s per-provider "Reconnect" action; the actual OAuth flow is delegated to the existing reconnection codepath.
