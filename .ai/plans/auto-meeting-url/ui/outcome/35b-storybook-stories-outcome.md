## Technical Patterns Used

### CSF Format
- `Meta<typeof Component>` with `satisfies` pattern
- `StoryObj<typeof meta>` type alias
- `render` functions for composition stories (AllStates, AllVariants, AllProviders)

### Render Stories with `args`
All `render: () => (...)` composition stories include `args` with the component's required props to satisfy Storybook's `StoryObj` typing (TS2322 error when `args` is missing).

### MockedProvider for GraphQL-Dependent Stories
- `MockedProvider` from `@apollo/client/testing/react`
- `MockLink.MockedResponse[]` type for mock data
- `maxUsageCount: Infinity` for mutation mocks
- Variable matcher pattern (`() => true`) for flexible mutation matching

### Labels-as-Props Pattern
- Pre-resolved label strings passed as `args.labels` — no `useAppTranslation` in story args
- Module-level `const labels` objects for reuse across stories

### Duplicate Import Fix
Combined `import type` + `import` from same module into single `import { X, type Y } from "..."` to satisfy `import-x/no-duplicates` lint rule.
