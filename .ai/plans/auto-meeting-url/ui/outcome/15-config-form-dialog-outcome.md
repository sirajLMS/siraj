## Design Decisions

- **Schema factory pattern**: `createMeetingConfigFormSchema(labels)` injects pre-resolved label strings into the zod schema (NOT a `t` function). This mirrors `sessionConfigForm.schema.ts` and `credentialForm.schema.ts`. Labels are resolved at the ViewModel layer and passed as plain strings.
- **Form ID**: Uses React `useId()` for stable, SSR-safe form IDs. The `<Box id={formId} component="form" onSubmit={handler}>` wraps the form content, and `EntityFormDialogActions` references the same `formId` via its `form` attribute.
- **EntityFormDialogActions**: `isLoading={saving}` — only true during mutation (NOT for "disabled when invalid"). The submit button uses `type="submit" form={formId}` so the form submission is handled by the `<Box component="form">` wrapper.
- **Test Config button**: Regular MUI `Button` (NOT `LoadingButton` — `@mui/lab` is not installed). Uses `startIcon={testing ? <CircularProgress size={16} /> : undefined}` pattern (matching `TokenExpiryWarning.tsx`).
- **Preview URL**: `TextField` with `slotProps={{ input: { readOnly: true } }}` (MUI v9 pattern — NOT a direct `readOnly` prop) plus icon button for copy-to-clipboard.
- **No `useAppTranslation`** in view component — all strings via `labels` / `enhancementLabels` props (Rule 7).
- **No `console.*`** — uses `logger` from `@/frontend/utils/logger` if needed.
- **MUI v9**: All style props in `sx` prop. No hardcoded colors — theme callback.
- **Cognitive complexity**: Extracted nested conditional JSX blocks (`TestConfigSection`, `TestConfigPreviewUrl`) and `if/else` chains (`resolveZodErrorMessage`, `buildUpdateInput`, `buildDetailsPayload`, `fetchGeneratedUrl`) to module scope to stay under sonarjs/cognitive-complexity max of 15.
