## Carry-forward knowledge

- **Where the "Accounting / Finance Manager" group grants live**: there is no
  "Finance Manager" group. All `accounting.*` permissions are granted to group slugs
  **`super_admin` and `academy_admin`** (see
  `backend/db/migration/33-accounting-permissions-and-enums.sql`,
  `36-accounting-payroll-permissions.sql`, `39-accounting-reports-permissions.sql`).
  `academy_admin` is the manager-level group all manager roles map to.
- **Auto-bundler flow**: drop an idempotent SQL file in `backend/db/migration/`, then
  run `applyCustomMigrations()` (exported from `backend/db/scripts/applyCustomMigrations.ts`;
  also runs automatically as part of `bun db migrate`) to generate the drizzle folder +
  update the sidecar. Applying grants to a dev/test DB requires `bun db migrate`
  (NOT run here — DB-affecting step left to the orchestrator/environment).
- Tests/seeders needing an "accounting operator" actor should assign the
  `academy_admin` group (or a per-user override) once the migration is applied.
