   - `CarryoverAggregateInstance` — minimal structural input (`teacherId` required;

     Drizzle select rows satisfy it without mapping).

   - `resolveDominantCurrency(instances, fallback)` — highest row count wins;
     `teacherPaidCurrency == null` rows don't vote; **any tie at the leading count
     resolves to `fallback` (the teacher's `rateCurrency`), even when the fallback
     does not appear in the rows**; empty/all-null input also yields `fallback`.
   - `computeTotalDurationHours(instances)` — `sum(calculatedDuration ?? 0) / 60`,
     round-half-even (banker's) to 2 decimals via internal `roundHalfEven` (epsilon
     1e-9 absorbs binary float noise), formatted with `toFixed(2)` → e.g. `"1.75"`.
   - `truncateWithEllipsis(text, maxLen)` — unchanged when `text.length <= maxLen`;
     otherwise `text.slice(0, maxLen - 3) + "…"` (result length = `maxLen - 2`; the
     ellipsis is a single `…` char, one code unit).
   - `minDate(dates)` / `maxDate(dates)` — accept `Date | string | null | undefined`
     (alias `DateLikeInput`); normalize to ISO calendar date `YYYY-MM-DD`
     (`Date.toISOString().slice(0, 10)`; strings sliced to 10 chars); return
     `string | null` (null when the list has no usable value) — matching the text
     `fromDate`/`toDate` columns on `carryover_balances`.
   - `pickDominantCurrency(rows)` — for report pages (`CarryoverRow`-shaped
     `{ teacherCurrency }`); deterministic ties (currency that first reached the
     leading count); empty page falls back to `CurrencyCode.SAR`, mirroring the
     `DEFAULT_TOTAL_CURRENCY` precedent in `session-audit.service.ts`.

## Design Decisions (beyond plan text)

- **Tie semantics tightened**: plan says "ties resolved to fallback". Implemented as
  "any tie at the leading count → fallback", including when fallback never appears
  in the rows (keeps derived amounts in a currency the teacher actually earns).
- **`minDate`/`maxDate` return ISO date strings, not `Date`s** — the target columns
  are text, and inserting a JS `Date` into a `text` column would persist a driver-
  dependent string. Consumers (bulkCreate §3.2) should use the returned string,
  or `null` → column default.
- **`pickDominantCurrency` empty-page default = SAR** matches the existing
  `session-audit.service.ts` `DEFAULT_TOTAL_CURRENCY` precedent; the plan specifies
  no fallback and the GraphQL aggregate field is non-nullable.
- **No exact half-cent tie is reachable** through `computeTotalDurationHours` (minutes
  are integers, so `hours × 100 = 5m/3` is never a half-integer); the half-even
  branch is still implemented per spec and float-noise cases are covered by tests.
