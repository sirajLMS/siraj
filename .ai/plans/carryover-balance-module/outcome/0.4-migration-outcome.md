## Carry-forward knowledge

- **DB pair discipline**: migrations must be applied to BOTH local DBs —
  `.env` (`siraj`, dev) and `.env.test` (`siraj_test`, tests). `run-test.ts` unsets
  `DATABASE_URL` so tests always read `.env.test`; moving fast it is easy to migrate
  only the dev DB and get "column does not exist" test failures.
- The hashed FK name `carryover_balance_items_2HYuvyPXlTJk_fkey` is **snapshot-order
  dependent**; match it in tests/consumers via constraint definition, not name.
- `drizzle-kit generate` will also emit `ALTER TYPE app_permission ADD VALUE` statements
  for any enum values newer than the last snapshot — even ones shipped via custom SQL
  migrations of other plans. Safe (idempotent transforms), but expect the noise.
- Repo migration folders carry `snapshot.json` in-folder (no `meta/` journal); the
  drizzle-orm migrator scans folder names directly.
