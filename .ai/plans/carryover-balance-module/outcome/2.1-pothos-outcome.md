## Adaptations from the plan (noted)

- **File location `pothos/teachers/` not `pothos/billing/`** — trackable-tasks 2.1
  (and the task assignment) place it under `teachers/`; the earlier R2 review note
  that moved GraphQL paths to `billing/` was superseded there.
- **Aggregates as a nested `CarryoverAggregates` object** instead of the plan's
  flattened page fields — matches the actual `CarryoverPage` backend type
  (`aggregates: {...}`) and the `PayrollReportPage` pattern; flattening would not
  type-check.
- **Result wrapper GraphQL names** (`CarryoverDeleteResult`, etc.) chosen to be
  globally unique; the Pothos export names match the assignment verbatim.
- **`paidStatus` stays a plain String** — `CarryoverPaidStatusFilter` is a
  string-union in `backend/types`, not a `backend/enum` enum, and registering a new
  enum is out of scope; the resolver task (2.2) should narrow/validate it against
  the union before calling the service.
