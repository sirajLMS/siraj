- **Heading/subheading**: `labels.drawer.sessionsHeading(count)` where `count = sessions?.length ?? balance.linkedSessionCount ?? 0` — the balance record's `linkedSessionCount` snapshot keeps the heading ("Linked sessions (N)") stable while the rows query is in flight.

- **Six columns** (`labels.drawer.sessionDate/student/subject/duration/amount/status`):
  - date: `formatDate(scheduledStartAt, locale, notSet)` (ISO string from the DateTime scalar, date-only per the prototype's "SESSION DATE").

  - status: reused payroll `CalculationStatusChip` with `statusLabels: Record<CalculationStatus, string> = payrollLabels.status` (same `DashboardBillingPayroll` reuse pattern as `SessionAuditDataGrid`); `null` renders `notSet`.
- **Drawer title** switched per CF-2: `labels.drawer.title(balance?.teacherName ?? "")` replaces the interim `balance?.teacherName ?? labels.title` fallback.
- Component JSDoc updated (no longer describes the missing-sessions state).
