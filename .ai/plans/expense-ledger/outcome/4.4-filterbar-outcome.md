## What was done

`frontend/common/views/dashboard/accounting/expenses/ExpenseFilterBar.tsx` (new,
~300 lines) — `"use client"`, **props-free store-bridge** filter bar mirroring
`CarryoverFilterBar.tsx`, bound directly to `useExpenseFilterStore` (task 4.3)
and translating in-component via `useAppTranslation(DashboardAccountingExpenses)`
(chips/carries precedent for leaf components). Per implementation.md §5.5:

- **Title search, debounced 300 ms** — `useDebouncedTitleInput` copies the
  carryover `useDebouncedSearchInput` pattern verbatim (local input state,
  render-time re-sync on external resets, `setTimeout` push to
  `store.setTitle`). `maxLength` 200 to match the CSV route's title cap.
- **Type multi-select** — MUI `Select multiple displayEmpty` (SessionAudit
  `StatusFilterSelect` idiom) over all four `ExpenseType` codegen enum members;
  armed with `isExpenseType` string-guard (`no-unsafe-enum-comparison` avoided
  via a widened `readonly string[]` view of the enum array). Collapsed preview
  renders colored `ExpenseTypeChip`s (2 max, then a plain `+N` overflow chip);
  empty selection shows the filter label in `onSurfaceVariant`.
- **Expense-month picker** — `AppDatePicker` with `views={["year","month"]}`,
  `openTo="month"`, `format="yyyy-MM"` (carryover `BulkToExpenseModal`
  precedent); store string parsed via date-fns `parse` + `isValid` guard, and
  picker changes are `format`ted back to `YYYY-MM` (null/invalid → null =
  all months).
- **Payment-date range** — `AppDateRangePicker`, exact copy of the carryover
  `DateRangeFilter` glue (empty string ↔ null mapping). The group label reuses
  the existing `column.paymentDate` key ("Payment date") because the filters
  group ships no range-group label — **no locale keys were added**, so
  `types/en/ar` + snapshot regeneration were not needed.
- **Include-deleted toggle + Clear** — same `FilterActions` shape as carryover
  (Switch, then Clear button shown only while any filter is active). Per plan
  §5.5 the toggle is **visible to all viewers**: the resolver re-gates
  `includeDeleted` server-side (2.2 outcome — silently stripped unless
  `ACCOUNTING_EXPENSES_MANAGE`/super-admin), so the UI does not hide it.
- Layout/accessibility: `Paper variant="outlined"` + wrapping `Stack`
  (`{ xs: "column", md: "row" }`), RTL-safe flex tokens only; search input and
  month picker carry `aria-label`; the multi-select has an
  `InputLabel`/`labelId` pair; Clear button labeled by `t.filters.clear`.

Prototype inspected: **only** `expense-ledger-list.png` (single image); row
data treated as placeholder and not copied.
