  `profileHrefForTeacher({ teacherId })` when `teacherId`/`teacherName` exist,

- `ExpenseValueCell` — plain text with muted dash when absent;

- `ExpenseTypeChip` / `ExpenseSourceChip` (task 4.5) in the type and source

- `ExpensesToolbar` — Bulk Delete + selection-count chip (`selectedCount`)

- `ExpensesAggregateFooter` — `SectionPanel` with `AggregateAmount`

- `useExpensesExport` — file-local export hook (mirrors `useCarryoverExport`):
  busy lock + `exportFailed` error toast / `exportTruncated` warning toast.
- Main component: `buildExpensesColumns` via `useExpensesColumns`,
  `usePageLocalRowSelection` (page turns clear the selection), server
  pagination via `buildServerPaginationOptions`, `ErrorState`+`refetch` on

## Key decisions

- **Aggregate-key ↔ enum mapping** (task-flagged): row `type` values are the
  GraphQL codegen enum (`ExpenseType.Salaries === "SALARIES"`), but the server
  reports `rowCountByType` keyed by the **backend display name** (`"Salaries"`).
  `AGGREGATE_KEY_BY_TYPE` (+ explicit `EXPENSE_TYPES` tuple) maps keys back
  through a guard loop (`expenseTypeFromAggregateKey`) — no switch on enums, no
  `as` casts; unknown keys render the count without a chip. Mirrors the
  view-model's `EXPENSE_TYPE_EXPORT_VALUE` translation table.
- **Columns** (§5.3 + prototype): title, type chip, teacher, value+currency,
  paymentDate, expenseDate (raw YYYY-MM string), source chip, note, createdAt,
  actions. `note`/`source`/`teacher` non-sortable.
- **Selection**: controlled `rowSelectionModel={{ type: "include", ids }}` via
  `usePageLocalRowSelection` (same hook as carryover); `checkboxSelection` only
  when `canManageExpenses`; `disableRowSelectionOnClick`.
- **Prototype**: inspected `prototype/expense-ledger-list.png` only (single
  image). Matched toolbar split (bulk-delete left, export+add right), column
  set (prototype's RECIPIENT/PERIOD = teacher/expenseDate), footer total +
  per-type tallies. Placeholder row data not copied. Omitted the prototype's
  colored-dot legend in favor of the real type chips.
- **Deleted row state** (4.8 test contract): strike-through title + Deleted
  badge chip; Edit/Delete menu items disabled on such rows (server treats
  already-deleted deletes as idempotent no-ops; hiding keeps the UX honest).
