# Outcome — Task 3.3: i18n namespace `dashboard.accounting.expenses`

- **Date**: 2026-09-06
- **Status**: ✅ Complete

## What was done

Created the `dashboard.accounting.expenses` locale namespace per implementation.md §7.1,
following the corrected carryover convention (types leaf + EN/AR leaves +
`namespaces/*.namespace.ts` loader + eager `messages.ts` wiring). Both locale surfaces
(eager `messages.ts` server tree + lazy `*.namespace.ts` client loaders) are wired, per
`shared/locale/AGENTS.md` "keep both surfaces in sync".

Key groups:

- `title`, `empty`, `loadError`
- `column.*` — title, type, teacher, value, paymentDate, expenseDate, source, note, createdAt
  (EN/AR verbatim from §7.1)
- `type.*` — `Salaries` / `Marketing` / `Logistics` / `Technology` (enum-display captions)
- `source.*` — `Manual` / `FromCarryover` (source chip captions)
- `action.*` — addNew, edit, delete, bulkDelete, viewSource, plus `exportCsv` (toolbar
  Export CSV per §5.3, mirroring the carryover namespace's extra)
- `filters.*` — title, searchPlaceholder, type, expenseDate, paymentDateFrom,
  paymentDateTo, includeDeleted, clear (filter bar per §5.5)
- `modal.form.*` — titleAdd, titleEdit + the §7.1 form labels (title, type, teacher,
  value, currency, paymentDate, expenseDate, note) + submit, cancel
- `modal.delete.*` — title, `summary(title, value, currency)` typed interpolation (the
  confirmation shows title + value + currency per task 5.2), reason + reasonPlaceholder
  (max 500 chars, matching `deletedReason` column), confirm, cancel
- `modal.bulkDelete.*` — `title(count)` CLDR-plural, confirm, cancel
- `validation.*` — titleRequired, valueNegative, expenseDateInvalid, paymentDateInvalid
  (verbatim §7.1) plus valueRequired + currencyRequired (form rules from §5.4 that §7.1
  omitted; wording aligned with the `errors.expenses` leaf from task 1.3)
- `error.*` — notFound, alreadyDeleted, deleteViaUnpay, typeImmutableForSalaries,
  valueImmutableForSalaries (verbatim §7.1)
- `success.*` — created, updated, deleted (verbatim) + `bulkDeleted(count)` CLDR-plural
- `aggregate.*` — totalValue, rowCount

EN pluralization: 1/other branches. AR pluralization: full CLDR 0/1/2/3–10/11+ branching
(e.g. 1: "مصروف واحد", 2: dual "مصروفين", 3–10: "٣–١٠ مصروفات", 11+: "مصروفاً").
Function-returning keys use `if`/`return` blocks (not nested ternaries) because
`sonarjs/no-nested-conditional` rejects nested ternaries — same as carryover.
