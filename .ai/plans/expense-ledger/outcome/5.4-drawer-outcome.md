# Outcome — Task 5.4: Expense detail drawer

- **Date**: 2026-09-07
- **Status**: ✅ Complete

## What was done

Created `frontend/common/views/dashboard/accounting/expenses/ExpenseDetailDrawer.tsx`
— a right-side drill-down drawer mirroring `CarryoverDetailDrawer`
(`frontend/common/views/dashboard/accounting/carryover/CarryoverDetailDrawer.tsx`)
styling and state conventions:

- Props: `{ expenseId, open, onClose }` per the task spec.
- Data: `useQuery(expenseQueryDocument, { variables: { id: expenseId }, fetchPolicy:
  "cache-and-network", skip: !open })` — the `Expense` query from the 4.1 documents
  (all 19 `ExpenseFields` including `deletedAt` / `deletedReason` /
  `sourceEntity` / `sourceEntityId`).
- RTL-safe anchor: `theme.direction === "rtl" ? "left" : "right"` (carryover
  convention).
- Header: interpolated `drawer.title(expenseTitle)` (falls back to the plain page
  `title` while the query resolves so there is no trailing empty slot), the
  `ExpenseTypeChip` from task 4.5 when `type` resolves, and the aria-labeled close
  `IconButton`.
- Deleted state: when the record is soft-deleted (`deletedAt !== null`), a
  `severity="warning"` banner (Alert + AlertTitle) above the summary showing
  `drawer.deletedBanner`, the formatted `deletedAt` timestamp, and the
  `deletedReason` line when present.
- Summary grid (`DetailField` caption-over-value pattern from the carryover
  drawer): value (primary headline via `formatLockedAmount`), currency
  (`modal.form.currency`), teacher, payment date, expense month,
  **provenance `ExpenseSourceChip`** (task 4.5) wired to `onViewSource =
  router.push("/accounting/carryover/<sourceEntityId>")` — the existing
  `app/(dashboard)/accounting/carryover/[id]/page.tsx` deep-link route that opens
  `CarryoverDetailDrawer` — plus created-by name, created-at / updated-at
  timestamps (locale-safe `formatOptionalDate` wrapper returning the `notSet`
  label for null timestamps), and a full-width note field.
- Loading / error / empty states mirror the carryover drawer: centered spinner
  while loading with no data, `Alert severity="error"` with `loadError` on query
  failure, empty body when the record is missing.

  the wave task instruction; clicking navigates away from the expenses list.
