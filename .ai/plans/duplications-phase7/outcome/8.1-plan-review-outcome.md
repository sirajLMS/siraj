## Step 4-5: Compliance Check & Findings

### Violations Found and Fixed

**VIOLATION 1 — MEDIUM: `no-underscore-dangle` oxlint rule**
- **Where:** `design.md` §3.1 (lines 94, 99, 104), `tasks.md` Tasks 1.1-1.3, Task 2.2
- **Issue:** Local helper names used leading underscore prefix: `_<action>MutationFields`, `_recurringScheduleFields`, `_scheduleQueryFields`, `_<domain>LabelLookup`
- **Rule:** Root `AGENTS.md` oxlint rules: "Identifiers with leading underscores are flagged." `backend/graphql/AGENTS.md` and `frontend/views/AGENTS.md` both inherit this rule.
- **Fix Applied:** Renamed all to non-underscore convention: `makePaymentMethodMutationFields`, `makeRecurringScheduleFields`, `makeScheduleQueryFields`, `makeDomainLabelLookup`

**VIOLATION 2 — MEDIUM: Pothos Field Factories pattern not referenced**
- **Where:** `design.md` §3.1, `tasks.md` Tasks 1.1-1.3
- **Issue:** Plan defaulted to local function extraction for backend GraphQL within-file clones without evaluating the existing `__shared__/` field factory pattern documented in `backend/graphql/AGENTS.md`
- **Rule:** `backend/graphql/AGENTS.md` "Pothos Field Factories" section documents completed extractions into `__shared__/` modules (e.g., `paymentFields`, `creditTransactionFields`)
- **Fix Applied:** Added evaluation step to each backend task: "Evaluate if existing `__shared__/` field factory pattern is more appropriate; if so, extend the shared factory instead"

**VIOLATION 3 — LOW: Cross-layer enum consolidation risk**
- **Where:** `design.md` §4.1
- **Issue:** Plan mentions consolidation option but should explicitly prohibit any approach that creates `shared → frontend/common/graphql/generated` dependency
- **Rule:** `shared/AGENTS.md` §Layer Isolation: "shared/ must NEVER import from `@/frontend/**`, `@/backend/**`, or `@/app/**` (ESLint enforced)"
- **Status:** Already addressed in design.md §4.1 line 174: "Forcing consolidation would create a `shared → frontend/common/graphql/generated` dependency, violating `shared/` layer isolation." — explicitly states jscpd-ignore is the recommended option. **No fix needed.**
