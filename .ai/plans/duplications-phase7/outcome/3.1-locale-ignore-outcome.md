# Task 3.1 — shared/locale Within-File & Cross-File Clones (Real Code Extraction)

## What was found

- `.jscpd.json` did NOT include `shared/locale/**` in its `ignore` array.
- `bun check:duplicates` reported ~20 clone pairs involving `shared/locale/` files — both within-file clones (ar/en parallel implementations) and cross-file clones (locale types ↔ frontend view types).
- **POLICY CHANGE:** User explicitly forbade using `.jscpd.json` ignore patterns or `// jscpd:ignore` directives. All clones were fixed by extracting shared code.

## What was done — 6 fix groups across 19+ files

### 1. Auth cross-file clones (4 pairs eliminated)
**Files:** `shared/locale/ar/auth/index.ts`, `shared/locale/en/auth/index.ts`
- Replaced inline `login` + `impersonation` blocks with imports from sibling files (`login.ts`, `impersonation.ts`).
- Files went from ~52 lines to ~13 lines each.

### 2. Errors within-file clones (6 pairs across 3 files)
**Files:** `shared/locale/types/errors/index.ts`, `shared/locale/ar/errors/index.ts`, `shared/locale/en/errors/index.ts`
- **Types file:** Extracted `SchedulingSharedErrors` interface (9 overlapping props between `SchedulingErrors` and the flat section). Made `ErrorsLabels` extend `StudentErrors`, `CategoryErrors`, `UserErrors`, `PermissionGroupErrors`, `SchedulingSharedErrors`. Removed ~30 flattened property declarations (now inherited via interface extension). Kept 4 scheduling-only flat props that are accessed by backend services.
- **ar + en files:** Extracted 6 sub-object `const`s at module scope (`student`, `category`, `user`, `scheduling`, `permissionGroup`, `teacher`). Replaced inline nested objects with references. Replaced ~30 flattened property declarations with spreads (`...student`, `...category`, etc.).

### 3. Onboarding within-file clone (1 pair eliminated)
**File:** `shared/locale/types/dashboard/parents/onboarding.ts`
- `fields` and `placeholders` had identical key sets with `string` type. Extracted `OnboardingFieldKey` union type and `OnboardingFieldLabels` mapped type `{ readonly [K in OnboardingFieldKey]: string }`.

### 4. Dashboard cross-file type clones (1 pair eliminated)
**Files:** `shared/locale/types/dashboard/admin/view.ts`, `shared/locale/types/dashboard/classes/details.ts`
- `admin/view.ts`: Extracted `ClassAdminActionsLabels`, `ClassInfoLabels`, `ClassMetadataLabels`, `ClassRateLabels` interfaces (exported).
- `classes/details.ts`: Imported shared types from `admin/view.ts`, used intersection types for `performance` and `instanceDetails`.

### 5. Dashboard cross-file impl clones (4 pairs eliminated)
**Files:** `ar/dashboard/admin/view.ts`, `ar/dashboard/classes/details.ts`, `en/dashboard/admin/view.ts`, `en/dashboard/classes/details.ts`
- Extracted `adminActions`, `classInfo`, `metadata`, `rate` as exported `const` sub-objects in `admin/view.ts`.
- `classes/details.ts` imports these and reuses them. For ar: `adminActions` destructured (excluding `overrideRateButton`). For en: only `classInfo` and `rate` shared (different `adminActions` strings and `metadata` values).

### 6. Profile + cross-layer frontend clones (4 pairs eliminated)
**Files:**
- `shared/locale/types/dashboard/supervisorPortal/profile.ts` — imported `ProfileAdminResetPasswordLabels` from `types/profile/index.ts` instead of re-declaring 22-line block.
- `frontend/common/views/dashboard/classes/recurring/types/recurringSchedulesListViewModel.types.ts` — imported `ColumnLabels`, `ActionLabels`, `FilterLabels` from `shared/locale/types/dashboard/classes/recurringSchedulesList.ts` instead of re-declaring.
- `shared/locale/types/dashboard/teachers/availability.ts` + `frontend/common/views/dashboard/teachers/availability/types.ts` — extracted `TeacherAvailabilityTableLabels` interface in locale types, aliased as `WeeklyAvailabilityGridLabels` in frontend.
- `frontend/common/views/dashboard/classes/details/useClassDetailsLabels.ts` — imported `ClassRateLabels` from locale types, used intersection `& ClassRateLabels` instead of re-declaring 20 rate fields.
