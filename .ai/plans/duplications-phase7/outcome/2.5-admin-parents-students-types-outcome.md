# Task 2.5 — admin/parents/students/types.ts Within-File Clones

## What was found

`frontend/common/views/dashboard/admin/parents/students/types.ts` had a within-file clone: `StudentsViewLabels` and `StudentDirectoryDataGridLabels` shared 13 identical field definitions (index, student, email, status, hoursPerWeek, classesLeft, actions, showingOf, previous, next, viewProfile, viewHistory, noEntries, statusLabels).

## What was done

- Extracted `StudentDirectorySharedLabels` interface at module scope with the 13 shared fields.
- `StudentsViewLabels` now extends `StudentDirectorySharedLabels` (adds pageTitle, pageSubtitle, mobileTitle, searchPlaceholder, addStudent, filters, globalRecord, weeklyHours, enrollmentStatus, enrollmentLabels).
- `StudentDirectoryDataGridLabels` now defined as `type StudentDirectoryDataGridLabels = StudentDirectorySharedLabels` (empty subtype — used type alias instead of empty interface to avoid `@typescript-eslint/no-empty-object-type` lint error).
- `StudentDirectoryCardListLabels` remains separate (different shape).
