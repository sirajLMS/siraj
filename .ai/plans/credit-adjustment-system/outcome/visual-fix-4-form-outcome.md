# Visual Fix 4 — Selected-Student Summary Name Truncation (CreditAdjustForm)

On narrow viewports the deep-linked student's summary card in `frontend/common/views/dashboard/accounting/credits/CreditAdjustForm.tsx` let a long name render flush against the BALANCE caption/chip with zero separation. The row itself already carried the right contract — the name/block wrapper had `minWidth: 0, flex: 1`, the card row kept `gap: 1.5` between avatar, text and balance block, and the balance `Stack` already had `gap: 1` with `flexShrink: 0` — but the name `Typography` never truncated, so an unbreakable string simply overran the reserved flex space. The fix confines itself to the name `Typography` (CreditAdjustForm.tsx:411), which now spreads the same uncapped-ellipsis idiom used by sibling `StudentCreditsList.tsx`: `minWidth: 0`, `overflow: "hidden"`, `textOverflow: "ellipsis"`, `whiteSpace: "nowrap"` alongside its existing `fontWeight: 600, fontSize: 14`, so the name yields with an ellipsis while the balance caption/chip keeps its guaranteed 8px internal rhythm and never shrinks. The change is purely presentational (no colors, no direction-dependent properties — logical flow is inherited from the flex row, so RTL is unaffected) and leaves every other node in the form untouched.
