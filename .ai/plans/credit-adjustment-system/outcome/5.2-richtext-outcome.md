## Summary

Delivered `RichTextEditor`, a controlled TipTap-based HTML editor following the
`input/<widget>/` convention. Toolbar (Bold, Italic, Underline, BulletList,
OrderedList) maps 1:1 to the sanitizer allowlist from `1.4-sanitizer-outcome.md`

horizontalRule) are explicitly disabled so the editor cannot emit markup the
server would strip.

`aria-pressed` state in sync.

## API surface (carry-forward for Task 5.6 CreditAdjustForm)

Import (barrel): `import { RichTextEditor, type RichTextEditorProps } from "@/frontend/common/components/ui/input";`

```ts
interface RichTextEditorProps {
  value: string;                        // HTML; "" = empty document
  onChange: (html: string) => void;     // HTML per edit; "" when cleared
  label?: string;                       // MUI InputLabel (shrink), aria-linked
  helperText?: string;                  // MUI FormHelperText (form error text)
  error?: boolean;                      // error border + helper text styling
  disabled?: boolean;                   // toolbar disabled + non-editable
  required?: boolean;                   // asterisk via FormControl/InputLabel
  id?: string;                          // base id for aria-labelledby wiring
}
```

**Wiring with the store (see `5.1-store-outcome.md`)**:

```tsx
const notes = useCreditAdjustFormStore(s => s.notes);
const setNotes = useCreditAdjustFormStore(s => s.setNotes);
<RichTextEditor
  value={notes}
  onChange={setNotes}
  label={t.reasonLabel}          // from dashboard.billing.creditAdjustment
  error={notesTouched && notes.trim() === ""}   // n.b.: "" when doc is empty
  helperText={...}
  required
/>
```

Behavioral contract form code may rely on:
- **Empty is exactly `""`** — `editor.isEmpty` normalization means
  `AC-5.3` “empty or whitespace-only” validation can test `value === ""` +
  a whitespace trim; no HTML stripping needed for emptiness.
- **No echo loops**: `onChange` never fires on mount and never re-fires when
  the consumer merely echoes the last value back through the `value` prop
  (guarded by a last-emitted ref; verified by test).
- **External resets work**: a `value` prop change to `""` (e.g. store
  `reset()`) clears the document via `setContent` without firing `onChange`.
- **i18n**: toolbar `aria-label`s come from `useAppTranslation(Translation.Ui.RichText)`;
  no hardcoded strings; RTL inherited from theme (logical `paddingInlineStart`
  for lists; no `dir` forced).
- **SSR-safe**: `"use client"`, `immediatelyRender: false`; no window access.
- Keyboard: StarterKit keymaps give Mod-B / Mod-I / Mod-U emphasis shortcuts
  out of the box; toolbar buttons are `aria-pressed` toggles that preserve
  editor focus (`onMouseDown.preventDefault`).
