- **Status**: ✅ Done

## Approach — mocked-module service test (matches `backend/services/billing` convention)

`recordAdjustment` opens its own `db.transaction` internally and performs bare `db`
reads (`assertStudentExists`, recovery lookup), so a `runInRollback` wrapper cannot
isolate it (fixture rows would be invisible to the service's own connection). The
suite therefore follows the established `billing-management.service.test.ts`
pattern: `await mock.module(...)` registrations before the deferred SUT import,
capture-buffer mocks for every repo/service seam, real `@/backend/lib` (real
`DomainError`/`ValidationError`/`NotFoundError`/`ForbiddenError` classes + **real
`sanitizeRichText`**, so the sanitization matrix exercises the genuine control) and
real `deriveAdjustmentIdempotencyKey` (derived-key assertions match production hashing).
`tErrors` is a purpose-built `ErrorsLabels` stub via `assertIsErrorsLabels`.

Mocked specifiers (exact import specifiers used by `credit.service.ts`):
`@/backend/db/drizzleDb`, `@/backend/db/repo/billing` (CreditRepository),
`@/backend/db/repo/students`, `@/backend/db/repo/teachers`,
`@/backend/db/repo/shared` (advisory lock), `@/backend/services/billing/permission-utils`,
`@/backend/services/billing/quota.service`, `@/backend/services/billing/carryover-handoff` (spy).

### Root cause of the two failing legacy suites (owned by concurrent work, not this task)

Both suites fail at **fixture setup** (`setupTestEntities` → `class_instances` insert) with:

```
error: column "calculated_duration" of relation "class_instances" does not exist (SQLSTATE 42703)
```

The working tree contains uncommitted teacher-payroll schema additions
(`backend/db/schema/classes/scheduling.ts`: `calculated_duration`, `payroll_calculated_at`,
`payroll_calculated_by`, …) that have not been pushed to the test database
(`.env.test`). Every DB test that inserts `class_instances` fails identically; suites
without class-instance fixtures (both credit-adjustment suites above) pass. This task's
only touched file is a fully-mocked test that never reaches a real DB — it cannot be
the cause (each suite runs in its own runner process and never loads the new file).
