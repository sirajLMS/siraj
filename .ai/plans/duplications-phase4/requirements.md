## 1. Overview

### 1.1 Motivation

Despite three prior plans, `bun check:duplicates` still reports **528 clones** (528 pairs, 12,315 duplicated lines / 3.82%, 72,387 duplicated tokens / 4.27%) across 3,118 files. The largest category is frontend↔frontend (470 pairs) — explicitly **out of scope** for Phase 4. Phase 4 targets the **app/, shared/, backend/, scripts/ and codegen.ts** pairs only:

- 3 app/ pairs (route boilerplate)
- 3 shared↔backend cross-layer enum duplicates
- 25 backend↔backend pairs (services, repos, schema, GraphQL)
- 5 scripts/codegen.ts pairs (config & helper script duplication)

Total Phase 4 scope: **~36 pairs** (independent of the frontend 470), each individually small (<30 lines, 75-1781 tokens) but compounding to ~600+ duplicated lines of non-frontend source. Eliminating these keeps clone statistics honest and removes long-deferred drift risk (e.g. timezone enum is 446 lines duplicated across two files with 1781 tokens — the largest clone in the repo).

### 1.2 Scope

**In scope (54 currently-jscpd-flagged files across 36 clone pairs):**

| Layer | Pairs | Reason |
|-------|-------|--------|
| `backend/` ↔ `backend/` | 25 | Service/repo/schema/GraphQL boilerplate (intra-/cross-file) |
| `shared/` ↔ `backend/` | 3 | Cross-layer enum duplicates (canonical = `shared/constants/`) |
| `app/` ↔ `app/` | 3 | Next.js route shims / metadata boilerplate |
| `scripts/` ↔ `scripts/` | 4 | Health/unused script duplication (config + types) |
| `codegen.ts` ↔ `codegen.ts` | 1 | Codegen output config object duplication |

**Out of scope (explicit):**
- `frontend/**` ↔ `frontend/**` clones (470 pairs) — slated for a future phase.
- `shared/locale/**` intra-namespace clones (translation pattern duplication) — by-design structural.
- `frontend/` ↔ `shared/` locale import clones (6 pairs in `/shared/locale/` only) — structural to locale pattern.
- Any test file duplications (`*.test.ts(x)` — already excluded via `.jscpd.json`).
- Any test requiring a Next.js server (see §3 below).

### 1.3 The Cross-Layer Timezone Problem (largest clone, deferred through phases 1-3)

`backend/enum/shared/timezone.enum.ts` (449 lines) is a **stale copy** of `shared/constants/iana-timezone.enum.ts` (449 lines), which is regenerated by `scripts/generate-iana-timezone-enum.ts`. The backend copy has **57 active importers**; the shared copy has 8 (frontend, shared lib, scripts). Per AGENTS.md, `shared/` is canonical and `backend/enum/shared/` must not duplicate it. Phase 4 will repoint the 57 backend imports to `@/shared/constants/iana-timezone` and delete the stale backend copy.

## 4. Acceptance Criteria (EARS)

**AC-1 (Enum cleanup):** WHEN tasks 1.1-1.3 complete THEN the system SHALL have deleted `backend/enum/shared/currency.enum.ts`, `backend/enum/shared/timezone.enum.ts`, and `backend/enum/classes/class-instance-detail.enum.ts` with all backend importers repointed to `@/shared/constants/*`.

**AC-2 (Service extraction):** WHEN tasks 2.1-2.5 complete THEN the system SHALL have a `ParentServiceBase`, shared `resolveTeacherId`, `prepareMeetingConfigUpsert`, `createAuthSession`, and `build*InsertPayload` helpers; all call-sites updated; no behavioral change.

**AC-3 (GraphQL helpers):** WHEN tasks 3.1-3.6 complete THEN all in-scope Pothos object field-list duplication and resolver boilerplate SHALL be extracted into `_*Fields(t, …)` helper factories or `make*QueryField` factories.

**AC-4 (Repo factory extension):** WHEN task 4.1 completes THEN `backend/db/repo/billing/__shared__/billingRepoFactory.ts` SHALL expose a `makeBillingUpsertMany(table, slugCol, valueAdapter, toSelectType)` extension and pair #1 SHALL use it.

**AC-5 (Scripts dedupe):** WHEN tasks 5.1-5.4 complete THEN `scripts/health/__shared__/{log.ts,bin-resolver.ts,sub-loop-types.ts}` and `scripts/unused/__shared__/types.ts` SHALL exist and the five scripts pairs SHALL import from them.

**AC-6 (Codegen config):** WHEN task 5.5 completes THEN `codegen.ts` SHALL define a single `sharedGqlConfig` const shared by both codegen outputs.

**AC-7 (App routes):** WHEN tasks 6.1-6.3 complete THEN the three app/ route-shim clone pairs SHALL either consume `buildMeetingProviderPageMetadata` / `makeUserProfilePage` / `makeParentProfileRedirectPage` factories OR be added to `.jscpd.json` ignore with justification.

**AC-8 (Quality gate):** WHEN all tasks complete THEN `bun tsgo` SHALL report 0 errors, every modified file SHALL pass `sub-loop.ts --lifecycle codescene`, and `bun check:duplicates` SHALL show ≥31 fewer in-scope pairs vs. Phase 3 baseline.

**AC-9 (Knowledge propagation):** WHEN task 9.1 completes THEN root `AGENTS.md` Important References, layer AGENTS.md, instruction files, and a `docs/<domain>/<topic>.md` doc SHALL be updated with patterns/rationale for cross-layer enums, service-base pattern, Pothos field factories, and billing-repo-factory extension.
