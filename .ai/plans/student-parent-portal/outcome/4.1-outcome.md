## Carry-forward knowledge for future subtasks

- Locale namespace registration is a 7-step process: (1) types file in `shared/locale/types/dashboard/reports/`, (2) en impl in `shared/locale/en/dashboard/reports/`, (3) ar impl in `shared/locale/ar/dashboard/reports/`, (4) namespace def in `shared/locale/namespaces/dashboard/reports/`, (5) update 3 barrels (types/en/ar/namespace reports indexes), (6) add import + property to `shared/locale/types/message.ts` MessageSchema, (7) add import + property to BOTH `shared/locale/en/messages.ts` AND `shared/locale/ar/messages.ts` `dashboardTranslations` object. Missing step 7 causes `Property 'monthlyAppraisal' is missing` tsgo errors.
- `sed -i 'Na ...'` insertion loses leading indentation — always verify with `cat -A` and re-indent if needed.
- `defineNamespace` uses lazy `import().then()` — but `messages.ts` uses EAGER imports (`import { xEn } from "..."`). Both patterns coexist; the eager path is for the base `dashboardTranslations` object, the lazy path is for the `defineNamespace` registry. Both must point to the same locale file.
- `MonthlyAppraisalLabels` shape: `teacherView` (list page), `form` (teacher appraisal form dialog), `studentParentView` (list + detail + feedback modal), `errors`. Tasks 4.2/4.3 will consume these via `useTranslations("dashboardTranslations.monthlyAppraisal")` (or the equivalent hook).
