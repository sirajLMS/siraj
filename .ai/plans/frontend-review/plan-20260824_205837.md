# Frontend Refactoring Plan

## MUI v9 & React 19 Migration Fixes

No MUI v9 violations found in the packed subset (all style props correctly routed through `sx`/`styled`, no deprecated icon names, no legacy Grid). React fixes are limited to two low-severity items:

**1. Remove unnecessary client directives in streaming fallbacks.**

```diff
--- app/(dashboard)/dashboard/loading.tsx
-"use client";
 import { Box, Skeleton } from "@mui/material";
```
(identical edit in `app/(dashboard)/quotas/loading.tsx` and `app/(dashboard)/settings/whatsapp/loading.tsx`)

**2. Wire the dead lifecycle mutation (HIGH).** `parents/[id]/lifecycle/page.tsx` currently renders a permanent no-op. Introduce a client container:

```tsx
// frontend/common/views/dashboard/parents/lifecycle/ParentLifecycleClientContainer.tsx
"use client";
import { useMutation } from "@/apollo-client-react-shim"; // "@apollo/client/react"
import { changeParentLifecycleStatusMutationDocument } from "@/frontend/common/graphql/sharedDocuments";

export function ParentLifecycleClientContainer({ parent }: Props) {
  const [mutate, { loading }] = useMutation(changeParentLifecycleStatusMutationDocument);
  return (
    <ParentLifecycleContainer
      parent={parent}
      isUpdating={loading}
      onUpdateLifecycle={async (status, reason) => {
        await mutate({ variables: { parentId: parent.id, newStatus: status } });
      }}
    />
  );
}
```
