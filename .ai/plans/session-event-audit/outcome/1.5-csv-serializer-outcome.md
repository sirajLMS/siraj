## Exact CSV contract (column order + header labels)

Exact header line (22 columns, comma-joined, in `SessionAuditReportRow`
declaration order):

```
instanceId,scheduledStartAt,scheduledEndAt,durationMinutes,actualStartAt,actualEndAt,bookingTimezone,currentStatus,calculatedDuration,teacherPaidAmount,teacherPaidCurrency,calculationStatus,isPartialPercentage,payrollNote,payrollCalculatedAt,teacherId,teacherName,studentId,studentName,subjectId,subjectName,teacherDuePaymentDate
```

- **Header labels are the camelCase field names** (not the localized grid
  labels) — mirrors the payroll export precedent, keeps the file machine-joinable.
- The specs' extra join-back columns are all present: `teacherId`, `studentId`,
  and the class-instance id (named `instanceId`, matching the row contract).
- **Line separator: CRLF (`\r\n`)** — same as `app/api/payroll/export/route.ts`.
  The payload ends with a trailing CRLF (splitting a serialized output on
  `\r\n` yields one extra empty segment).
- **Escaping (RFC 4180):** cells containing `,`, `"`, `\n`, or `\r` are wrapped
  in double quotes; embedded `"` is doubled. Quoting happens AFTER the formula
  prefix is applied.
- **Formula-injection hardening:** cells whose first character is `=`, `+`,
  `-`, `@`, `\t`, or `\r` get a leading single quote (`'`) before any quoting
  (OWASP set — the 4 symbols specs TB.5 names, plus tab/CR to match the
  project's existing payroll export hardening).
- **Nulls:** every nullable field (`actualStartAt`, `actualEndAt`,
  `bookingTimezone`, all 7 payroll fields, `teacherDuePaymentDate`) serializes
  as an empty cell. Numbers go through `String(...)`; enum values serialize to
  their string values.
