## Navigation contracts

- Row click (any cell except `payrollNote` / `actions`) → `router.push("/classes/<instanceId>/audit")`.
- Enter on a focused grid cell (same field exclusions) → same navigation (7.2).
- "Open audit page" row action, rendered **only** when `canManageReports` → `router.push("/classes/<instanceId>/audit?openOverride=1")`.
- Cells with their own interactive content (note popover button, action button) never trigger row navigation — enforced by a field filter, so no cross-file edits to `PayrollNotePopover` were needed.

## Column spec decisions

- Field names equal the `SessionAuditReportSortField` wire values, so the server
  sort mapping is a plain `Record` lookup (no casts). Non-sortable columns:
  `subjectName`, `currentStatus`, `isPartialPercentage`, `payrollNote`, `actions`
  (the sort enum has no members for them).
- **Calculation-status chip labels**: reused Plan 3's `CalculationStatusChip` (per
  slice brief) with labels from the payroll namespace loaded directly
  (`useAppTranslation(DashboardBillingPayroll)`) — the exact precedent of
  `ClassAuditDetailsCard.tsx`; the 4.2 view-model intentionally exposes only the
  session-audit namespace.
- **Subject + actions column headers** also come from the payroll namespace
  (`column.subject`, `column.actions`) — the session-audit namespace has no such
  keys and no new locale keys were invented (7.1 is another wave's verification).
- **Payment date** is surfaced per AC-6.4 inside the calculation-status cell: a
  success-colored `CheckCircleOutlined` + tooltip with the localized payment
  date-time — only for paid rows with a payment date; no separate column header
  key exists in the namespace.
- Scheduled-duration / calculated-duration / paid-amount cells delegate to the 4.5
  formatters (`formatDurationMinutes`, `formatPaidAmount`); room entry/exit cells
  use `SessionTimeCell` — localized via `formatOpenSessionTime` /
  `formatEndSessionTime`, muted `onSurfaceVariant` placeholders (`Not joined` /
  `In progress`) when the timestamp is missing, otherwise a `Tooltip` with the two
  function keys `tooltip.rawUtc(iso)` + `tooltip.bookingTimezone(tz)` (5.3).
- Aggregate footer card renders only when `aggregates.totalPaidCurrency !== null`
  (first-load gap guard per the 4.2 contract); zeros render as real values.

## Server sorting + pagination wiring

- `sortingMode="server"`, controlled `sortModel=[{ field, sort }]` from the
  view-model state; `onSortModelChange` maps back through
  `GRID_FIELD_TO_SORT_FIELD` and calls `setSort(field, OrderSortDirection.*)`.
  Unmapped fields (DataGrid can still emit events for `sortable: false` columns
  in edge cases) are ignored.
- Pagination via `buildServerPaginationOptions` — `onPageChange: setPage`,
  `onPageSizeChange: setPageSize`, `rowCount: totalCount`, page-size options
  `25/50/100/200` (AC-5.3).

## States

- Loading: `loading={isLoading}` → AppDataGrid skeleton overlay (never fabricated rows).
- Empty: `emptyMessage={labels.emptyState.title}` → AppDataGrid no-rows overlay.
- Error: `error !== null` replaces the grid with the project `ErrorState` (default
  Common-namespace copy) + `onRetry={refetch}`.

## Accessibility (7.2 grid portion)

- Grid `ariaLabel={labels.title}`; sortable headers get `aria-sort` from MUI
  (asserted in tests); chips carry aria-labels (4.4); note popover trigger is a
  native focusable button (5.2); row navigation is keyboard-accessible via Enter
  on any focused navigating cell.
