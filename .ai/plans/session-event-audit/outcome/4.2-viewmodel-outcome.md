## Behavior contract (how the internals work — needed by consumers)

- **Mount wiring**: one `useEffect` calls `hydrateFromUrl()` then `startSessionAuditUrlSync()` and returns its cleanup (the 4.3 wiring recipe verbatim). Hydration reads the live `window.location.search`; sync rewrites the URL via `history.replaceState` after the store's 100 ms debounce.
- **Search debounce**: raw `search` from the store is debounced 300 ms (`SEARCH_DEBOUNCE_MS`); the **debounced** value feeds both the GraphQL filter and the export URL. Consumers should render `search`/`setSearch` raw. `hasActiveFilters` deliberately uses the **raw, trimmed** search (not the debounced one), so the Clear affordance appears the instant the operator types (amended by the FIX-R grid slice, `fix-r-grid-outcome.md`).
- **Variables mapping**: `filter` is `null` when no filter is active; otherwise `{ teacherId, studentId, dateFrom, dateTo, currentStatuses, search, includeDeleted: null }` with empty values nulled (`currentStatuses` spread to a mutable array only when non-empty). `sort` is always sent as `{ field: sortField, direction: sortDirection }` (store default = service default: `scheduledStartAt` desc). `limit = pageSize`, `offset = page * pageSize`. `fetchPolicy: "cache-and-network"`.
- **Aggregates narrowing**: runtime type guards (`typeof` + `Reflect.get`, zero `as` casts) narrow the codegen `unknown` JSON scalars; missing/invalid values fall back to all-zero counts, `totalPaidAmount: "0.00"`, `totalPaidCurrency: null`. `totalPaidAmount` is guaranteed non-null inside `SessionAuditReportAggregates`.
- **CSV export**: fetches `"/api/accounting/reports/export?..."` with statuses comma-joined and `sortDirection.toLowerCase()`; always sends the sort pair (the route rejects a half pair). Downloads via the blob/anchor pattern so `X-Export-Truncated` and `Content-Disposition` stay readable; returns `{ truncated }` so the container can toast the truncation notice; failure is logged via `logger.error` and returns `null`.
- **Permission flag**: `canManageReports` = `AppPermission.AccountingReportsManage` (the route/page view permission is enforced server-side, so no view flag is exposed).

## Notes for the container / grid agents

- The aggregate card (`SessionAuditAggregateCard`) accepts `totalPaidCurrency: CurrencyCode | null` (nullable since the FIX-R grid slice): mount it unconditionally — its status/paid counts render even while the currency is unknown, and only the currency total hides. `rowCountByStatus`/`rowCountByPaid` pass straight through.
- `labels.status` keys (`open`, `end`, `Absent`, `absent_student`) match the codegen `SessionAuditStatus` wire values — usable directly as a `Record<SessionAuditStatus, string>` lookup for the grid's status column and as the `statusLabels` prop of the chip/card.
- DataGrid pagination wiring: `onPageChange: setPage`, `onPageSizeChange: setPageSize` (both already 0-based/clamped inside the store).
- While the query is loading for the first time, `aggregates` is the zero-filled default — the card renders real zeros, never a raw gap.

## Deviations from the wave brief

1. **Search included in the GraphQL filter + export URL** beyond the four listed filter fields — required by the 4.3 store contract ("VIEW-MODEL debounces 300 ms") and specs.md (AC search 300 ms debounce); without it the search input would be dead. The four listed fields are exactly as specified.
2. **`error` typed as `ErrorLike | null`** (Apollo's exported error type) instead of a boolean, so the grid can read the message; `refetch` exposed as a void-wrapped callback.
