## Props interface (verbatim contract)

```tsx
export interface SessionAuditPaidRowCounts {
  readonly paid: number;
  readonly unpaid: number;
}

export interface SessionAuditAggregateCardProps {
  /** Summed teacher paid amount for the filtered page, as a decimal string. */
  readonly totalPaidAmount: string;
  /** Dominant currency of the summed paid amount. */
  readonly totalPaidCurrency: CurrencyCode;
  /** Row count per audit status; every status key must be present. */
  readonly rowCountByStatus: Record<SessionAuditStatus, number>;
  /** Paid/unpaid row tallies for the filtered page. */
  readonly rowCountByPaid: SessionAuditPaidRowCounts;
  /** Localized summary-section labels from the session-audit namespace. */
  readonly labels: SessionAuditLabels["aggregate"];
  /** Localized per-status labels from the session-audit namespace. */
  readonly statusLabels: SessionAuditLabels["status"];
}
```

- `SessionAuditStatus` is the shared-constants union (`@/shared/constants/classes/session-audit-status`); `CurrencyCode` is the codegen enum (`@/frontend/common/graphql/generated/gql/graphql`) — matching the `formatLockedAmount` signature directly, no mapping.
- The ViewModel narrows the GraphQL `JSON` aggregates once at its boundary (`aggregates.rowCountByStatus: unknown` → `Record<SessionAuditStatus, number>`; `rowCountByPaid` → `SessionAuditPaidRowCounts`) and destructures them into these props; the report page aggregates contract (`totalPaidAmount: String!`, `totalPaidCurrency: CurrencyCode!`, all four status keys always present) makes every prop required and non-null.

## Rendered behavior / conventions

- **Shell**: `SectionPanel` with a responsive `Stack` (column on xs, row from md, wrap, space-between) — mirrors the payroll report `AggregateFooter` precedent (`frontend/common/views/dashboard/accounting/payroll/PayrollReportsDataGrid.tsx:210-258`) promoted into a standalone component.
- **Total paid**: `labels.totalPaid` in `labelUppercase` at `theme.palette.onSurfaceVariant`, value in `titleLg` formatted via the canonical `formatLockedAmount(totalPaidAmount, totalPaidCurrency, locale)` (ISO-4217 minor-unit aware; renders `"EGP 120.50"`-style output including the currency). Locale comes from `useAppLocale()` (same as the payroll grid).
- **Per-status counts**: `SESSION_AUDIT_STATUS_ORDER` (`["open", "end", "Absent", "absent_student"]`, module-private) drives a row of `SessionAuditStatusChip` + count pairs in a fixed display order. Chips receive no `actualStartAt`, so they never pulse in the summary.
- **Paid/unpaid**: `labels.paidRows`/`labels.unpaidRows`, counts in bold colored `theme.palette.success.main` / `theme.palette.warning.main` respectively.
- **Zero states**: `0` counts and `"0.00"` totals render as real values (`formatLockedAmount("0.00", …)` → `"EGP 0.00"`-style), never hidden or swapped for a placeholder.
