## Props interface (verbatim contract)

```tsx
export interface PayrollNotePopoverProps {
  /** Raw payroll note of the report row; empty or missing notes render nothing. */
  readonly note: string | null | undefined;
  /** Localized cell labels; `viewFullNote` names the disclosure button and popover. */
  readonly labels: SessionAuditLabels["cell"];
}
```

## Rendered behavior

- **Null / empty / whitespace-only note** → `formatNoteCell` returns `null`, the
  component renders `null` (no stray icon for noteless rows).
- **Short note (≤ 200 chars)** → inline `Typography variant="body2"` with the
  full text (`whiteSpace: "pre-wrap"`, `overflowWrap: "anywhere"` — no-wrap
  URLs/IDs in notes cannot break the cell).
- **Long note (> 200 chars)** → `Tooltip title={preview}` (first 200 chars +
  `…`) over a small `IconButton` carrying `aria-label={labels.viewFullNote}`;
  click (or Enter/Space on the focused button — native `button` activation)
  first toggles a `Popover` anchored to the button (`anchorOrigin:
  bottom/center`), whose content is a `Typography` with `role="note"` +
  `aria-label={labels.viewFullNote}` containing the full untruncated note.
  Backdrop click / Escape closes via the standard `Popover` `onClose` path.
