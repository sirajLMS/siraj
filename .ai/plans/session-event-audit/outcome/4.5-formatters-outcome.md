## Behavior contract per formatter

- **`formatOpenSessionTime`** — `"Not joined"` (`cell.notJoined`) for null/undefined/blank/invalid-Date input; valid instants render as a localized date-time **in the booking timezone when the IANA zone is valid** (falls back to runtime-zone via `formatDateTime` on unknown zones); unparseable non-empty strings pass through trimmed (mirrors `formatWithFallback` convention in `frontend/common/components/intl/dateFormat.ts`).
- **`formatEndSessionTime`** — same machinery, fallback text is `"In progress"` (`cell.inProgress`); no booking-zone param per spec.
- **`formatDurationMinutes`** — rounds to whole minutes (`Math.round`), plain integer string; null/undefined/NaN/±Infinity → `cell.notCalculated` (`"—"`). Zero is a real value (`"0"`), not the placeholder.
- **`formatPaidAmount`** — delegates to the canonical `formatLockedAmount` from `@/frontend/common/lib/currency` (ISO-4217 minor-unit aware); missing/blank/non-numeric amount or missing currency → `cell.notCalculated`. `"0"` renders as `EGP 0.00`-style output, never the placeholder.
- **`formatNoteCell`** — returns a display model, not markup (the icon + hover popover are the grid cell component's rendering concern): trimmed `fullText`; `truncated: false` + full preview when ≤ 200 chars; otherwise `preview = first 200 chars + "…"`; `null` for empty/whitespace so cells render nothing.

## i18n / locale conventions

- All placeholder text comes from the `dashboard.reports.sessionAudit` namespace's `cell` group (`SessionAuditLabels["cell"]` from `shared/locale/types/dashboard/reports/sessionAudit`); formatters take it as a `labels` argument (Rule 7 labels-object pass-down — ViewModel owns `useAppTranslation(Translation.Dashboard.SessionAudit)` and passes `labels.cell` down; pure formatters never call hooks).
- Locale rendering uses the project's shared date utilities: `parseDateInput` + `formatDateTime` (`@/frontend/common/components/intl/dateFormat`) and `getLatnLocaleTag` (`@/shared/lib/locale-tag`, Arabic → `ar-EG-u-nu-latn` for Latin numerals).
- Money pairs amount + currency via `formatLockedAmount` (the project's currency display convention), not ad-hoc `Intl` in the cell.
