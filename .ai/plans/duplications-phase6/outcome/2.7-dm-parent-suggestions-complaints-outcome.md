1. **Options files with JSX use `.tsx` extension** — `.ts` files with JSX cause TS1005/TS1109 parse errors.

3. **Render slots for layout differences** — adminComplaints and parentBilling use render function slots to handle fundamentally different layout structures (DesktopSectionPanel vs MobileContentStack).
4. **No `jscpd:ignore`** — All pairs resolved by true code extraction into shared scaffolds.
