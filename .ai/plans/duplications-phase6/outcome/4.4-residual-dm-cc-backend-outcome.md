## Technical Notes

- **Generic components**: `CurrencySelectController<T>` and `executeProfileSubmit<T>` use TypeScript generics to handle type-safe reuse across different form contexts.
- **react-refresh rule**: `.tsx` files exporting both React components AND utility functions trigger `react-refresh/only-export-components`. Fix: move utilities to separate `.ts` files.
- **SchedulingMode import**: `createRecurringClassDialogUtils.ts` needed `SchedulingMode` imported as a value (not `import type`) because `Object.values(SchedulingMode)` uses it as a value.
- **Drizzle schema helpers**: `primaryKeyColumn()` and `timestampColumns()` from `columnHelpers.ts` work for `users.ts` but break type inference for `class-category.ts` / `class-subject.ts` — likely due to differing column configurations (e.g., `.$type<>()` annotations, unique constraints) that interact with spread-based column definitions.
