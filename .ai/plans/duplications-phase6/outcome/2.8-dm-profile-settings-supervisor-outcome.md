## Patterns Used

- **Config-based scaffold**: `*Shared.tsx` exports a shared component accepting props + `config`/`options` object. D/M files are thin wrappers that import the scaffold and pass tier-specific config (e.g., `settingsTabShared`, `profileSkeletonShared`).
- **Callback-based scaffold**: `*Shared.tsx` exports a shared component accepting `renderOwnView`/`renderBody`/`renderView` callback props. The callback handles layout-specific arrangement (e.g., `studentProfileShared`, `teacherProfileShared`, `notificationPreferencesTabShared`).
- **Shared dialog extraction**: When D/M files have structurally different layouts (DataGrid vs MobileCardList) but share dialog JSX blocks, extract only the shared dialogs (e.g., `sessionConfigDialogsShared`, `siteContentDialogsShared`).
- **Shared constant/helper extraction**: When D/M files share only a constant or utility function, extract to a minimal shared module (e.g., `monthlyReportsConstants.ts`, `recentApprovalCardLabels.ts`).
- No `jscpd:ignore` directives, no `.jscpd.json` changes, no `oxlint-disable` comments.
