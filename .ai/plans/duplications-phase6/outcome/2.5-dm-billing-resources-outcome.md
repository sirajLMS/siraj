## Pattern Used
- **Config-based scaffold**: `*Shared.tsx` exports a shared function accepting props + `config` object. D/M files are thin wrappers (7-19 lines) that import the scaffold and pass tier-specific config.
- **Factory-based scaffold**: `createX(config)` returns a component (used by `resourceUploadFormShared`).
- **Shared types extraction**: When D/M files have identical prop interfaces, extract to `types/*.types.ts` and have both import from it (one extends with tier-specific fields if needed).
- No `jscpd:ignore` directives, no `.jscpd.json` changes, no `oxlint-disable` comments.
