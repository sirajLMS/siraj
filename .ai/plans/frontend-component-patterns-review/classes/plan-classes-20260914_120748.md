# Frontend Component Patterns & UI Reuse Refactoring Plan (`classes`)

## Non-Negotiable Execution Protocol

For **every file modified** during implementation, the executing agent MUST run:

```bash
bun run scripts/health/sub-loop.ts <file-path> --lifecycle codescene
```

This executes `tsgo → oxlint → biome:check → lint:type-aware → check:duplicates → codescene --file`, short-circuiting at first failure. Exit code 0 is mandatory before proceeding to the next file.
