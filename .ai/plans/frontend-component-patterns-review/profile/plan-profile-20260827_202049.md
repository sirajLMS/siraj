# Frontend Component Patterns & UI Reuse Refactoring Plan (`profile`)

## Non-Negotiable Execution Protocol
- After **every** file modification, run `bun run scripts/health/sub-loop.ts <file-path> --lifecycle codescene` (strict order: tsgo → oxlint → biome:check → lint:type-aware → check:duplicates → codescene --file). Exit code 0 mandatory before proceeding.
- No cross-tier imports (`*.mobile.* ↔ *.desktop.*`), no `useMediaQuery`/`useViewport` outside switchers, no raw `@mui/x-data-grid` imports in views, never pay `paginationOptions` lip service by faking client mode on server slices.
- Every task below carries the mandatory five subtasks (QL/TE/SEC/SR/IV).
