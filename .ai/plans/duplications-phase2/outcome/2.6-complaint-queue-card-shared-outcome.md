## Slot Props Design

The scaffold exports two interfaces:

### `ComplaintQueueCardSlotProps`

Defines both component slots and layout constants for tier-specific styling:

**Component slots:**
- `Root: ComponentType<{ children: ReactNode; isUnanswered: boolean }>` — Outer container (desktop: Paper with answered/unanswered background; mobile: MobileCardListItem with accentBorder)
- `StatusBadge: ComponentType<StatusBadgeComponentProps>` — Status badge component (DesktopStatusBadge or MobileStatusBadge)
- `PrimaryActionButton: ButtonProps` — Primary action button (e.g. DesktopPrimaryPageAction)
- `EmailActionButton: ButtonProps` — Email action filter button (e.g. DesktopFilterButton)
- `DeleteActionButton: ButtonProps` — Delete filter button (e.g. DesktopFilterButton)

**Styling slots:**
- `EmailActionSx: SxProps<Theme>` — sx overrides for Email button (primary.main bg)
- `DeleteActionSx: SxProps<Theme> | undefined` — sx overrides for Delete button (mobile only; desktop passes undefined)

**Layout constants:**
- `HeaderDirection: "row" | "column"` — Header flexDirection
- `HeaderJustifyContent: string` — Header justifyContent
- `HeaderAlignItems: string` — Header alignItems
- `SubmitterGap: number` — Submitter info gap (desktop: 2, mobile: 1.5)
- `AvatarSize: number` — Avatar width/height (desktop: 48, mobile: 40)
- `StatusTextAlign: "right" | "left"` — Status text alignment (desktop: right, mobile: left)
- `ReceivedTimeMarginTop: number` — Received time label margin top (desktop: 1, mobile: 0.5)
- `ActionsDirection: "row" | "column"` — Actions box flexDirection
- `ActionsJustifyContent: string` — Actions box justifyContent

### `ComplaintQueueCardSharedProps`

Contains shared inputs: `row`, `labels`, `draftResponse`, `canManage`, `canDelete`, `onDraftChange`, `onAnswer`, `onDelete`, and the `slots` object.
