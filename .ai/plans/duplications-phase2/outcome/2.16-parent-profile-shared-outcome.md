## Slot Props Design

```typescript
export interface ParentProfileSlotProps {
  readonly ViewContentWrapper: React.FC<{ readonly children: ReactNode }>;
  readonly SectionPanel: React.FC<{ readonly title?: ReactNode; readonly children?: ReactNode }>;
}
```

**`ViewContentWrapper`**: Wraps the profile view-mode content. Desktop renders `Grid container > Grid size={{ xs: 12, md: 6 }} > Stack spacing={3}`, mobile renders `MobileContentStack`.

**`SectionPanel`**: Used only by the students section. Desktop uses `DesktopSectionPanel`, mobile uses `MobileSectionPanel`. Both accept `title?: ReactNode` and `children?: ReactNode`.

## Type Narrowing
