# Task 2.3: Meeting Provider Form Shared Scaffold

## Summary

Eliminated the desktop↔mobile clone for `meetingProviderForm` by extracting all shared form section rendering into a scaffold component with slot props for tier-specific wrappers and style configuration.

## Files

### Created
- `frontend/common/views/dashboard/admin/meeting-providers/form/__shared__/meetingProviderFormShared.tsx`
  - Scaffold with all shared form sections: LogoSection, IdentitySection, UrlAllowlistSection, CapabilitiesSection, ActionsBar, FormBody, FormLoadingState
  - Slot props: `MeetingProviderFormSharedSlots` (PageContainer, PageHeader)
  - Style props: `MeetingProviderFormSharedStyleProps` (12 configurable values + LoadingWrapper component)
  - Main export: `MeetingProviderFormShared`

### Modified
- `frontend/desktop/views/dashboard/admin/meeting-providers/form/meetingProviderForm.desktop.tsx`
  - Reduced from 404 → 54 lines (86% reduction)
  - Desktop-specific: padding 3, h6 variant, spacing 3/1.5, no fullWidth, justify flex-end, Paper loading wrapper
  - Passes BackAction (ArrowBackOutlined button linking to /meeting-providers)

- `frontend/mobile/views/dashboard/admin/meeting-providers/form/meetingProviderForm.mobile.tsx`
  - Reduced from 419 → 36 lines (91% reduction)
  - Mobile-specific: padding 2, subtitle1 variant, spacing 2.5/1, fullWidth buttons, Box loading wrapper
  - No BackAction (mobile navigation differs)

## Pattern Used
- **Scaffold with slots** following `docs/frontend/ui-shared-scaffold-pattern.md`
- Direct file path imports (no barrel re-exports) to avoid TDZ/circular dependency issues
- Module-level constants for `desktopSlots`, `desktopStyles`, `mobileSlots`, `mobileStyles` (no-object-type-as-default-prop)
- Spread props `{...props}` in view functions to eliminate residual clone boilerplate
