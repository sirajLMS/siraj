## Technical Notes

- **MUI v9 Typography**: `bodySm` is a custom theme typography variant not accepted by the `variant` prop. Fixed by using `sx={{ typography: helperTextTypography }}` instead.
- **theme.layout.radius.button**: Returns `MuiThemeBorderRadius` not standard CSS `BorderRadius`. Fixed by wrapping with `String()`.
- **Preview size**: 96px for common, 128px for desktop/mobile. Icon and progress spinner sizes scale accordingly.
- **Button layout**: Common uses vertical for circle shape, horizontal for square. Desktop uses horizontal always. Mobile uses fullWidth always.
- **Container wrapper**: Mobile wraps content in `MobileContentStack` with `gap={1.5}` via the `ContainerWrapper` slot.
