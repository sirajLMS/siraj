The desktop variant used string-based color `"text.secondary"` in `DetailRow` and the empty-state `Typography`. The scaffold uses the theme callback pattern `theme => ({ color: theme.palette.text.secondary })` consistently, which is the MUI v9-compliant approach. This aligns the desktop variant to the common variant's theme-callback pattern — no user-visible behavioral change.

The unused `_locale` parameter in `getDetailRows()` was removed (it was unused in both variants).
