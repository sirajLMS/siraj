# Task 1.1: CurrencyAutocomplete Shared Scaffold — Outcome

## Scaffold Interface

### File: `frontend/common/components/ui/input/currencySelect/CurrencyAutocompleteShared.tsx`

The scaffold exports `CurrencyAutocompleteShared`, a `React.FC<CurrencyAutocompleteSharedProps>` that encapsulates ALL shared presentation logic for the currency autocomplete component.

### Props (extends `CurrencyAutocompleteProps`)

```typescript
type CurrencyAutocompleteSharedProps = CurrencyAutocompleteProps & CurrencyAutocompleteSlotProps;
```

### Slot Props (`CurrencyAutocompleteSlotProps`)

| Slot Prop | Type | Purpose |
|-----------|------|---------|
| `LocaleEmojiComponent` | `React.FC<{ emoji: string }>` | Renders flag emoji in input start adornment |
| `CurrencyOptionRowComponent` | `React.FC<{ currency, locale, showSymbol }>` | Renders each currency option row in the dropdown |
| `getPopperSlotProps` | `(options: CurrencyAutocompletePopperOptions) => PopperSlotProps` | Factory for Autocomplete popper slot props |
| `getPaperSlotProps` | `(listAttached: boolean) => PaperSlotProps` | Factory for Autocomplete paper slot props |
| `optionRowSx` | `SxProps<Theme> \| undefined` | sx applied to each option row `<Box component="li">` |
| `fullWidthDefault` | `boolean \| undefined` | Default value for the `fullWidth` prop (mobile defaults to `true`) |

### Types File: `frontend/common/components/ui/input/currencySelect/types/currencyAutocompleteShared.types.ts`

Exports: `CurrencyAutocompleteSlotProps`, `CurrencyAutocompleteSharedProps`, `GetPopperSlotProps`, `GetPaperSlotProps`, `LocaleEmojiComponent`, `CurrencyOptionRowComponent`, `CurrencyAutocompletePopperOptions`.

Internal alias `AutocompleteInternalSlotProps` resolves `NonNullable<AutocompleteProps<CurrencyOption, false, false, false>["slotProps"]>` for popper/paper type extraction.

## What Was Extracted to the Scaffold

1. **Filter logic**: `createFilterOptions<CurrencyOption>` with stringify matching code, symbol, and label
2. **Input rendering**: `renderCurrencyInput` — TextField with search icon, locale emoji, currency symbol adornments
3. **Option rendering**: `renderCurrencyOption` — Box wrapper with option row component
4. **Autocomplete sx builder**: `buildAutocompleteSx` for `listAttached` border radius adjustments
5. **All hooks and handlers**: `useCurrencyCatalog`, `useAppLocale`, `useAppTranslation`, `useState` for internal open state, `useMemo` for filtered options, `useCallback` for getOptionLabel, handleOpen, handleClose, handleChange
6. **Resolved display values**: label, placeholder, helperText, error state, fullWidth resolution
7. **Full Autocomplete JSX**: Complete component with all props wired to slot props

## Behavioral Changes

**None.** The scaffold is a pure extraction — all behavioral logic (filtering, open/close handling, change handling, error display, option rendering) was moved verbatim from the original common variant. Tier-specific differences (emoji component, option row component, popper/paper slot props, option row sx, fullWidth default) are passed as slot props, preserving identical behavior in each tier.

## Cross-File Dependencies

- Desktop and mobile variants import **ONLY** from the scaffold path `@/frontend/common/components/ui/input/currencySelect/CurrencyAutocompleteShared` — never from each other or from common tier-specific paths.
- The scaffold imports types from `@/frontend/common/components/ui/input/currencySelect/types/currencyAutocompleteShared.types`.
- The `types/index.ts` barrel was updated to export all new shared types.
- No circular dependencies introduced.
