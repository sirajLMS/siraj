## Patterns Documented

### Pattern 1: View Component Scaffold (`__shared__/` Directory)
- **When**: Desktop and mobile view variants share significant presentation logic
- **Where**: `frontend/common/views/.../components/__shared__/*Shared.tsx`
- **How**: Scaffold with slot props for tier-specific components, sx styles, configuration
- **Import Rule**: Both desktop and mobile variants import ONLY from `__shared__/` — never from each other
