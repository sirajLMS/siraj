## Scaffold Design

### Options Interface (`WeeklyAvailabilityGridSharedOptions`)

All tier-specific differences are passed via an options object (no slot components needed — only styling varies).

```typescript
export interface WeeklyAvailabilityGridSharedOptions {
  readonly gridTemplateColumns: string;      // "100px repeat(7, 1fr)" / "70px repeat(7, minmax(64px, 1fr))"
  readonly headerPadding: number;            // 2 / 1
  readonly headerLabelVariant: "labelUppercase" | "labelSm";  // labelUppercase / labelSm
  readonly blockPadding: number;             // 1 / 0.5
  readonly rowMinHeight: number;             // 80 / 60
  readonly cellPadding: number;              // 0.5 / 0.25
  readonly gridMinWidth: number;             // 1000 / 600
  readonly momentumScroll: boolean;           // false / true
}
```

### Normalized Differences

- **Desktop `Typography variant="labelSm"` on block teacherName** → Scaffold uses `typography: "labelSm"` in `sx` (consistent with mobile and avoids variant prop vs sx inconsistency)
- **Desktop `Typography variant="labelMd"` on row time column** → Scaffold normalizes to `variant="labelSm"` (matching mobile, both are valid for time labels)
- **Desktop first Typography in block used `variant="labelSm"` prop**, mobile used `sx={{ typography: "labelSm" }}` → Scaffold uses `sx={{ typography: "labelSm" }}` for both (consistent approach)
