## Scaffold Design

### Slot Props Interface (`PaginationControlsSlotProps`)

Tier-specific styling is passed via slot props using `(theme: Theme) => string` callback functions for theme-dependent values:

- `rootGap`, `rootPaddingInline`, `rootPaddingBlock` — spacing units
- `inputWidth` — page input width in px
- `navButtonSize?` — optional fixed nav button size
- `borderColor(theme)` — border color resolver
- `backgroundColor(theme)` — non-embedded background resolver
- `embeddedTransparent` — whether embedded state is borderless/transparent
- `labelColor(theme)` — label text color resolver
- `navButtonBackground(theme)` — nav button background resolver
- `navButtonColor(theme)` — nav button text color resolver

### Shared Props Interface (`PaginationControlsSharedProps`)

- `page`, `pageCount`, `rowCount`, `pageSize`, `embedded?`, `flush?`, `onPageChange`
