## Slot Props Design

```typescript
export interface TeacherAvailabilityMonthDrawerSlotProps {
  /** Tier-specific calendar grid component (desktop or mobile). */
  readonly CalendarGridComponent: React.FC<{
    readonly labels: SearchScheduleLabels;
    readonly currentMonth: Date;
    readonly daysByDate: Readonly<Partial<Record<number, readonly TeacherAvailabilityGapItem[]>>>;
  }>;
  /** Drawer anchor position — "right" for desktop, "bottom" for mobile. */
  readonly drawerAnchor: "right" | "bottom";
  /** Drawer paper sx — tier-specific width/maxWidth/borderRadius. */
  readonly drawerPaperSx: Record<string, unknown>;
}
```

The three tier-specific variations:
- **CalendarGridComponent**: `TeacherAvailabilityCalendarGridDesktop` (desktop) vs `TeacherAvailabilityCalendarGridMobile` (mobile)
- **drawerAnchor**: `"right"` (desktop) vs `"bottom"` (mobile)
- **drawerPaperSx**: `{ width: 480, maxWidth: "100vw" }` (desktop) vs `{ width: "100%", maxWidth: "100vw", borderTopLeftRadius: 16, borderTopRightRadius: 16 }` (mobile)

All other rendering (DrawerHeader with close button, MonthNavigator with prev/next + flip RTL, DrawerContent with loading/error/grid) is identical and lives in the scaffold.
