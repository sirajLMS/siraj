## Key Patterns Documented
1. **Fail-open** for rate limiter operations during cold start
2. **retryTransient** for critical DB reads/writes (3 retries, 200ms→500ms→1000ms)
3. **Frontend retry** on SERVICE_UNAVAILABLE (max 2 retries, 1.5s/3s delays, via useRef pattern)
4. **Env-config transient short TTL** (30s throttle with `transientError` flag)
5. **`SERVICE_UNAVAILABLE`** error code (not `INVALID_CREDENTIALS`) for cold-start failures
