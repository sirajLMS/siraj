## Implementation Details

### `retryTransient` (backend/lib/retry.ts)
- Default: 3 retries, 200ms base delay, 2.5x multiplier (200→500→1000ms)
- Uses recursive helper `attemptWithRetry()` to avoid `no-await-in-loop` lint
- `isTransientError()` checks error codes (ECONNRESET, ETIMEDOUT, ENOTFOUND, EAI_AGAIN, ECONNREFUSED) and message patterns (timeout, connection, websocket, pool, termination, shutting down)
- Non-transient errors re-throw immediately
- Logs recovery at `info` level, each retry at `warn` level

### Tests (backend/lib/test/retry.test.ts)
- 14 tests, all pass
- Covers: transient retry success, exhaust retries, non-transient no-retry, zero retries, isTransientError variants, logger spy verification
- Uses `spyOn(logger, ...).mockImplementation()` pattern with `afterEach` mockRestore
