## Naming deviation from plan text (intentional)

The plan sketched `PROFIT_LOSS_REPORT_QUERY`, but
`frontend/common/graphql/sharedDocuments/AGENTS.md` mandates
`{entityName}QueryDocument` + `TypedDocumentNode<{EntityName}Query, {EntityName}QueryVariables>`
and the task itself says "documents named `{entityName}QueryDocument`". So the export is
`profitLossReportQueryDocument: TypedDocumentNode<ProfitLossReportQuery, ProfitLossReportQueryVariables>`.
Task 4.5's `useQuery(PROFIT_LOSS_REPORT, ...)` should read `useQuery(profitLossReportQueryDocument, ...)`
(the codegen output also exposes `ProfitLossReportDocument` via
`@/frontend/common/graphql/generated/gql/graphql`, but the sharedDocuments const is the convention).
