Notes on key design (carry-forward for dashboard shell + tab subtasks):

- `fx.chip(count)` / `fx.tooltip(pairs)` are the filter-bar FX warning chip +
  tooltip keys (implementation.md §5.4). The tooltip's `pairs` argument is the
  pre-joined pair string the caller builds (e.g. `"EUR → USD"`).
- `aggregate.excludedRows(count)` is the per-tab footer excluded-row count.
- `aggregate.dominantCurrency` is the footer caption naming the dominant
  original currency (plan added it beyond the §7.1 table).
- `status.positive` / `status.negative` / `status.breakeven` caption the Net
  Profit row coloring (green / red / grey, AC-6.3).
- AR terminology follows established sibling accounting files: "وسيلة الدفع"
  (payment method, as in `ar/dashboard/accounting/payments.ts`), "ولي الأمر"
  (parent — corrected the §7.1 table's "ول الأمر" typo), "الباقة", "الفاتورة",
  "العملة السائدة". AR pluralization follows the sibling 0/1/2/3–10/11+ form
  pattern.

`package.json`. Zero-missing-keys is enforced by the compile-time type system:
both `dashboardAccountingProfitLossEn` and `dashboardAccountingProfitLossAr`

key. `bun run tsgo` reports zero errors under `shared/locale/**` — key parity
confirmed. The runtime snapshot check additionally verified both snapshots
serialize exactly 39 keys.
