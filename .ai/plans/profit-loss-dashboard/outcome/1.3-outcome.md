## Method Signature

```ts
export async function findProfitLossExpenses(
  input: { month: string; limit: number; offset: number },
  tx?: DBTransaction
): Promise<{ rows: Omit<ProfitLossExpenseRow, "convertedAmount">[]; totalCount: number }>
```

- Flat single-object input (`{ month, limit, offset }`) per the service-layer call site in
  `implementation.md` §3.4, plus the optional `tx` trailing param used by every method in this
  namespace.
- Return rows are typed as `Omit<ProfitLossExpenseRow, "convertedAmount">` — the DB layer
  deliberately does **not** populate `convertedAmount`: currency conversion is the service
  layer's concern (§3.4 spreads the row and assigns `convertedAmount` via `convertCurrency`),
  which completes the type into the full dashboard shape. Initial typing as the full
  `ProfitLossExpensesPage` failed tsgo (`convertedAmount` missing) and was corrected to the
  Omit projection.
