## Summary

Created `frontend/common/views/dashboard/accounting/profit-loss/EmptyMonthState.tsx`, the E16
zero-data panel rendered when the selected accounting month has no rows in any tab. It reuses
the project's established viewport-agnostic empty-state primitive
`EmptyState` from `@/frontend/common/components/ui` (barrel-reachable via
`frontend/common/components/ui/state/index.ts` → `ui/index.ts`), passing an
`EventBusyOutlined` glyph, and forwards an optional `sx` placement prop so the composing tab
panel can position it without content changes.

All copy comes from the compile-time i18n bundle via
`useAppTranslation(DashboardAccountingProfitLoss)` — the `empty.title` /
`empty.description` keys created by Task 3.3 ("No data for this month" /
"Try a different month or check back later." in EN, mirrored in AR). No hardcoded strings,
no hex colors (the primitive itself uses `theme.palette.text.secondary`), icon is the MUI v9
`*Outlined` naming, and the shared `EmptyState` centers content direction-free, so RTL and
mobile widths read identically.

## API (carry-forward for the Phase 5 tabs / dashboard shell)

```tsx
<EmptyMonthState />            // or with placement tweaks
<EmptyMonthState sx={{ py: 10 }} />
```

- Render it when `paymentsPage.totalCount + expensesPage.totalCount + incomePaymentsPage.totalCount === 0`
  (all three tabs empty for the selected month). It holds no data logic of its own.
- Accepts a single optional `sx` prop (`SxProps<Theme>`); `title`, `subtitle`, and icon are fixed.
