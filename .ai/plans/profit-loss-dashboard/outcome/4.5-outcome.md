### Task 4.5 — `ProfitLossDashboard.tsx` (unchanged from the interrupted run; verified)

`frontend/common/views/dashboard/accounting/profit-loss/ProfitLossDashboard.tsx`:

- Composes `GlobalFilterBar` with `fxWarnings={viewModel.fxWarnings}` (Task 4.2's
  carry-forward contract) above MUI `Tabs` with the four tabs in persisted-store order
  (`PROFIT_LOSS_TABS` = payments / expenses / income / profits).
- **State**: `useProfitLossViewModel({})` only — no duplicate `useQuery` in the shell;
  the single multi-tab query lives inside the hook. Tab switching reads `activeTab`
  from the persisted Zustand store (`onTabChange` → `setActiveTab`), so switching is
  instant with no refetch.
- **Body routing** (`renderTabBody`): load-error → `ErrorState onRetry={refetch}` (the
  ui/state primitive); empty month → `EmptyMonthState`; otherwise the
  `ResponsiveViewSwitch` with lazily-imported tier views. The intercepts guarantee the
  tier views never see the error/empty states.
- **Loading skeleton**: no `AppSkeleton` component exists in this repo — the
  project's pattern is `LoadingState` (ui/state) for shells and the accounting
  first-load scaffolds for lists (`DesktopListStateGate` spinner,
  `MobileListCardSkeletons` cards), which the tier views use. Noted per Task 4.5's
  "AppSkeleton pattern" instruction: the closest established equivalent was used.
- **Accessibility**: `Tabs aria-label={labels.title}` (native MUI roving-keyboard
  navigation); tab change is announced via the standard MUI tab semantics.
- **i18n**: all strings from `viewModel.labels` (`dashboard.accounting.profitLoss`
  namespace — `tab.*`, `title` all confirmed present in EN + AR; no new keys needed).
- **Styling**: sx-only, theme palette only, no hardcoded colors.

wrong copy for a query failure; with the dead branches gone, no error string is
needed in the tier views at all. The desktop `DesktopSectionPanel`'s duplicated
`title={labels.title}` (header already shows it) was dropped. Tier views render:
page header + first-load skeleton + the active tab's
`PaymentsTab`/`ExpensesTab`/`IncomePaymentsTab`/`ProfitsTab`.
