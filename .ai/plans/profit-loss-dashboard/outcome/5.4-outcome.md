## Summary

Created `frontend/common/views/dashboard/accounting/profit-loss/ProfitsTab.tsx`, the executive
summary tab of the P&L dashboard. A single `<Box component="table">` summary table (matching the
`CarryoverDetailDrawer` table idiom — `Box`-component table markup, `borderCollapse`, divider
row rules) renders 4 rows, each with a `scope="row"` header cell per AC-6.3 accessibility:

1. **Income Payments** — `summary.totalIncomePayments`
2. **Total Payments** — `summary.totalPayments`
3. **Total Expenses** — `summary.totalExpenses`
4. **Net Profit** — `summary.netProfit`, sign-colored (AC-6.3)

- **Sign coloring** (AC-6.3): resolved once from the numeric value —
  `theme.palette.success.main` when positive (green), `theme.palette.error.main` when negative
  (red), `theme.palette.text.disabled` when zero/absent/NaN (grey). No nested ternaries in JSX
  (extracted to `netProfitSign` / `netProfitStatusColor` helpers).
- **Net Profit Margin** (AC-6.5, E6/E7): rendered as a secondary inline figure next to the Net
  Profit amount — `<margin label>: <value>%` when `Total Payments > 0`, `—` when there is no
  income base (server already sends `netProfitMargin: null` in that case, the UI mirrors it).
- **Export CSV** (AC-6.4): `ExportButton` preset (shared `@/frontend/common/components/ui`
  barrel) → `GET /api/profit-loss/summary/export?month=<month>&currency=<currency>`, fetched
  and downloaded via the blob + object-URL + anchor pattern used by
  `IncomePaymentsTab`/`useDownloadInvoicePdf`; failures log via `@/frontend/common/utils/logger`
  and never reject, so the busy lock always clears. Button disabled while exporting/loading or
  when `summary === null`.
- **i18n**: every string comes from the `labels` prop (`ProfitLossLabels` slice of the
  ViewModel: `labels.aggregate.*`, `labels.action.exportCsv`, `labels.status.*`,
  `labels.tab.profits`). No `useAppTranslation` call in the tab (ViewModel owns translations).
- **Accessibility**: `th scope="row"` for each row header; the Net Profit amount carries an
  `aria-label` with the full phrase ("Net Profit: X CUR, Profit/Loss/Break-even"); the section
  wrapper has `aria-label={labels.tab.profits}`.
- Amounts formatted with the shared `formatAccountingMoney`; currency rendered beside the value
  in the report's target currency (AC-6.2 dominant-currency figures come pre-converted from the
  backend).

### Props contract (for the Phase 5 dashboard shell)

```tsx
type ProfitsTabProps = Pick<ProfitLossViewModel, "labels" | "summary" | "month" | "currency" | "isLoading">;
<ProfitsTab {...slice} />  // shell picks these off useProfitLossViewModel
```

Deliberately self-contained (own export fetch + busy state), same as the sibling
`IncomePaymentsTab` — no callbacks beyond the props above.
