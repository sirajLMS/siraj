## Summary

Created `frontend/common/views/dashboard/accounting/profit-loss/IncomePaymentsTab.tsx` — the
Income Payments tab of the P&L dashboard. It consumes the ViewModel (never edits it) via a
`Pick<ProfitLossViewModel, ...>` props slice (`labels`, `incomePage`, `month`, `currency`,
`isLoading`, `onIncomePageChange`, `pageSize`), so the Task 4.5 shell can pass the whole
ViewModel straight through (extra fields are structurally fine for a `Pick`-typed component).

### Grid

- `AppDataGrid` wrapper with server pagination via `buildServerPaginationOptions`. The current
  page index comes from the persisted filter store (`useProfitLossFilterStore(s => s.incomePage)`)
  because the ViewModel exposes the setter but not the raw index — same store, no state duplication.
- Columns per AC-5.2: payment date (`formatDate` locale-aware), invoice number, student, parent,
  package plan, method chip (`PaymentMethodChip` — rendered in-cell, dash when null), amount
  (`formatLockedAmount` with the row's own currency). Absent linked values render `—`.
- Row click → `router.push('/billing/invoices?invoiceId=...')` when the row carries an invoice
  id; rows without one (free-form payments) are inert — the AC's `/students/[id]` alternative was
  not wired because the row type carries no student id, only `studentName`.

### Footer

- Total Income Payments + dominant currency (falls back to the selected report currency while
  the aggregate is still null on first load).
- Dominant-currency caption line (hidden when null) and excluded-row-count caption
  (`labels.aggregate.excludedRows(count)`, hidden when 0 — no dead chrome).
- `ExportButton` preset → `fetch('/api/profit-loss/income/export?month=…&currency=…')`, blob
  download via object URL, honoring the route's `X-Export-Truncated` contract; disabled while
  exporting/loading or when the month has no rows. Same fetch-and-blob idiom as the
  session-audit export in `useSessionAuditReportsViewModel.ts`.

### Conventions honored

- All copy through `labels` (owned by the ViewModel); no `useAppTranslation` in the tab.
- `theme.palette` via theme callbacks only; typography theme variants (`titleLg`, `bodyMd`).
- No `console.*` — `logger` from `@/frontend/common/utils/logger`. RTL-safe (no physical
  `align: "right"` on the amount column). No hardcoded fixture data — rows come solely from
  `incomePage`. Prototype image was the only visual reference; no Tailwind/hex values copied
  (the prototype has no `.html` sibling in the directory).
