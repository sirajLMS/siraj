## Shared Helpers Created

3. **`writeSimulationAuditLog(params: SimulationAuditLogParams): Promise<void>`** — Generic audit log writer to `adminAuditLogs` table

- `SimulationAuditLogParams` — Input type for `writeSimulationAuditLog` (actorUserId, targetUserId, action, description, metadata, ipAddress)

## Design Decisions

1. **Helper functions, not a class** — Services have different signatures (impersonation has `targetUserId`, group simulation has `groupSlug`). A class would force artificial interface conformance.
2. **`getSimulationExpiresAt` parameterized by `ttlMs`** — Each service keeps its own `IMPERSONATION_TTL_MS`/`GROUP_SIMULATION_TTL_MS` constant but delegates the calculation.
3. **`assertSessionOwnership` takes `errorKey`** — Uses `StringErrorKeys<ErrorsLabels["auth"]>` mapped type to restrict to string-only error keys (avoids function-typed properties like `demoGroupNotFound`).
4. **Local `writeAdminAuditLog`/`writeGroupSimulationAuditLog` wrappers** — Each service keeps a thin local wrapper that passes entity-specific description strings to the shared `writeSimulationAuditLog`.
5. **Direct module import for `__shared__/simulationBase.ts`** — Per policy, no barrel import when caller and shared file are in the same barrel scope.
