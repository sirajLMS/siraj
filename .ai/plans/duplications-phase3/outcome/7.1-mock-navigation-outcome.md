## Helper API

```typescript
// test/ui/components/helpers/mockNavigation.tsx

export interface MockNavigationOptions {
  /** Locale returned by useParams() (default "en"). */
  locale?: string;
  /** Whether to include useRouter/usePathname/useSearchParams/redirect in next/navigation. Default true. */
  includeRouter?: boolean;
  /** Whether to also mock @/shared/i18n/routing and @/shared/i18n/navigation. Default true. */
  includeI18nMocks?: boolean;
  /** Search params for useSearchParams() (default empty URLSearchParams). */
  searchParams?: URLSearchParams | string;
  /** Custom push mock shared across all router mocks. When omitted, fresh mock() is used. */
  mockPush?: ReturnType<typeof mock>;
  /** Locales array for @/shared/i18n/routing. */
  locales?: readonly string[];
  /** Default locale for @/shared/i18n/routing. */
  defaultLocale?: string;
  /** Whether to include redirect in next/navigation mock. Default true. */
  includeRedirect?: boolean;
  /** Whether to include useSearchParams in next/navigation mock. Default true. */
  includeSearchParams?: boolean;
  /** Whether routing router mock includes replace/prefetch. Default true. */
  routingIncludeReplaceAndPrefetch?: boolean;
  /** Whether next/navigation and navigation router mocks include replace/prefetch. Default true. */
  includeReplaceAndPrefetch?: boolean;
}

export async function mockNextNavigation(
  pathname?: string,
  opts?: MockNavigationOptions
): Promise<void>;
```

### Usage Examples

```typescript
// Standard full mock (most files)
await mockNextNavigation("/dashboard", { locales: ["ar", "en"], defaultLocale: "en" });

// Params-only next/navigation, routing 4 methods
await mockNextNavigation("/dashboard", { includeRouter: false, routingIncludeReplaceAndPrefetch: false });

// Only next/navigation mock (no i18n mocks)
await mockNextNavigation("/dashboard", { includeI18nMocks: false, includeRedirect: false, includeSearchParams: false });

// With custom searchParams
await mockNextNavigation("/profile", { locales: ["ar", "en"], defaultLocale: "en", searchParams: "tab=profile" });

// With custom mockPush (for assertion checking)
const mockPush = mock(() => {});
await mockNextNavigation("/dashboard", { mockPush, locales: ["ar", "en"], defaultLocale: "ar", routingIncludeReplaceAndPrefetch: false, includeReplaceAndPrefetch: false });
```

## Design Deviations

1. **`.tsx` extension instead of `.ts`**: The design doc (section 10.1) shows `mockNavigation.ts`, but the helper contains JSX (a `LinkComponent` mock component), requiring `.tsx` extension for TypeScript to parse the JSX syntax.

2. **Bun's `mock.module()` API instead of Vitest's `vi.mock()`**: The design doc shows `vi.mock("next/navigation", ...)` but the actual codebase uses Bun's async `await mock.module("next/navigation", ...)` from `bun:test`. The helper was adapted to use the correct API. This means the helper is `async` and callers must `await` it.

3. **Three modules mocked, not just one**: The design doc focuses on `next/navigation`, but all 15 files also mock `@/shared/i18n/routing` and `@/shared/i18n/navigation` (except `CronManagementView.test.tsx` which only mocks `next/navigation`). The helper handles all three modules with the `includeI18nMocks` option to control whether the i18n mocks are included.

4. **Additional options beyond design**: The helper includes options not specified in the design doc but required by the actual variations across files: `includeSearchParams`, `includeRedirect`, `routingIncludeReplaceAndPrefetch`, `includeReplaceAndPrefetch`. These handle files that historically omit certain methods or features.

5. **`mock` import from `bun:test` retained in consumer files**: Most consumer files still import `mock` from `bun:test` for other `mock.module()` calls (e.g., `useLanguageSwitch`, `next/link`, `RequirePermission`). Only the navigation-related mock blocks were extracted; other mocks remain inline.
