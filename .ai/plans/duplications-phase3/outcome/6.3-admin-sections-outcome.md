# Task 6.3 — Profile Admin Section Consolidation

## Summary

Consolidated 3 duplicated admin section components (`AdminOnlySection.tsx`, `StudentAdminSection.tsx`, `SupervisorAdminSection.tsx`) into thin wrappers around a new shared scaffold component `AdminSectionShared` with slot props.

## Files Created

- `frontend/common/views/dashboard/profile/components/__shared__/adminSectionShared.tsx`
  - Exports `AdminSectionShared` (main scaffold component) and `EditResetPasswordSlot` (edit-mode helper)
  - Handles: SectionPanel wrapper, StatusBadge + ResetPasswordIconButton in view mode, TextField with MenuItem options in edit mode, ResetPasswordDialog with useAdminResetPassword hook, useProfileFieldAccess for canAdminResetPassword
  - Slot props: `InfoField` (component), `extraViewFields`, `extraEditFields`, `renderEditResetPassword`, `resetPasswordRef`

## Files Modified (refactored to thin wrappers)

1. `frontend/common/views/dashboard/student/profile/sections/AdminOnlySection.tsx`
   - Student portal profile admin section — delegates to `AdminSectionShared`
   - Keeps: `getStudentStatusLabel`, `getStudentStatusColor`, `InfoField`, `STUDENT_STATUS_OPTIONS`
   - Uses `studentAccount` badge category, `StudentStatus` enum (5 statuses)

2. `frontend/common/views/dashboard/students/profile/sections/StudentAdminSection.tsx`
   - Students management profile admin section — delegates to `AdminSectionShared` + `EditResetPasswordSlot`
   - Keeps: `getStudentStatusLabel`, `getStudentStatusColor`, `InfoField`, `STUDENT_STATUS_OPTIONS`
   - Uses `renderEditResetPassword` slot for edit-mode reset password section with ref forwarding

3. `frontend/common/views/dashboard/supervisor/profile/sections/SupervisorAdminSection.tsx`
   - Supervisor profile admin section — delegates to `AdminSectionShared`
   - Keeps: `getAccountStatusColor`, `InfoField`, `SUPERVISOR_STATUS_OPTIONS`
   - Uses `staffAccount` badge category, `AccountStatus` enum (2 statuses: Activated/Deactivated)

## Bug Fixes Introduced by Consolidation

- **AdminOnlySection (student)**: Original had buggy nested `ResetPasswordDialog` wrapped inside a `Tooltip` inside an `InfoField` value — the dialog was rendered as a tooltip child (invisible/broken). Fixed by shared component using proper `IconButton` with `KeyOutlined` to trigger `ResetPasswordDialog`.
- **SupervisorAdminSection**: Same buggy nested `ResetPasswordDialog` inside `Tooltip` pattern. Fixed by shared component.
- **SupervisorAdminSection**: Original edit mode didn't wrap in `SectionPanel` — now consistent with other admin sections via shared component.

## Slot Props Design

```typescript
interface AdminSectionSharedProps {
  mode: "view" | "edit";
  sectionTitle: string;           // SectionPanel header
  accountStatusLabel: string;     // InfoField label / TextField label
  resetPasswordSuccess: string;   // useAdminResetPassword success message
  resetPasswordError: string;     // useAdminResetPassword error message
  InfoField: InfoFieldComponent;  // Slot: each domain has slightly different spacing
  statusBadgeCategory: "studentAccount" | "staffAccount";
  statusColor: StatusColor;       // Mapped from enum by wrapper
  statusLabel: string;            // Mapped from enum by wrapper
  editStatusOptions: readonly StatusOption[];
  editStatusDefaultValue: string;
  canEditStatus: boolean;
  targetUserId: string | null;
  userName: string;
  userEmail: string;
  extraViewFields?: React.ReactNode;
  extraEditFields?: React.ReactNode;
  renderEditResetPassword?: React.ReactNode;
  resetPasswordRef?: React.RefObject<AdminResetPasswordSectionRef | null>;
}
```

## What Wrappers Keep Locally

Each wrapper retains domain-specific logic that cannot be shared:
- **Status → color mapping**: Different enum types (StudentStatus vs AccountStatus) with different color values
- **Status → label mapping**: Different translation namespaces and key structures
- **InfoField component**: Each has slightly different `spacing` values (0.5 vs 0.25)
- **Status option constants**: Different enum values and ordering
- **useProfileFieldAccess scope**: Supervisor uses `undefined as ProfileScope | undefined`, others use `undefined`
