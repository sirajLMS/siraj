## Approach

### Helper Design (`makeFileJunctionTable.ts`)

- **Typed config object** (`FileJunctionConfig<TColumns>`) — avoids dynamic string-key access (no `as` casts, satisfies `no-unsafe-type-assertion`)
- **Generic over columns** — `TColumns extends FileJunctionColumns` lets Drizzle infer full `PgTableWithColumns` return type with all column properties accessible
- **`entityColumnName: keyof TColumns & string`** — typed property name for the entity FK column, used in the index callback without any `as` casts (Drizzle's `ExtraConfigColumn` type accepts it)
- **Reuses existing helpers** — `primaryKeyColumn()` and `createdAtColumn()` from `@/backend/db/schema/__shared__/columnHelpers`
- **Direct module import** — imports `storageFiles` directly from `@/backend/db/schema/storage/storage` (not barrel), required to avoid circular dependency TDZ
- **Column order preserved** — `id`, `fileId`, `entityFk`, `usageType`, `createdAt` matches existing snapshot order to prevent column reordering migrations
