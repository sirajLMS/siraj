## Helper API

```typescript
// Pattern 1: Static title — no params, no async fetch
export async function buildTranslatedMetadata(
  selector: (t: Translations) => string
): Promise<Metadata>

// Pattern 2: ID-suffixed — params, no async fetch
export function buildIdSuffixedMetadata(title: string, id: string): Metadata
export async function buildIdSuffixedTranslatedMetadata(
  selector: (t: Translations) => string, id: string

// Pattern 3: Entity name prefixed — params, async fetch
export function buildEntityNamePrefixedMetadata(
  entityName: string | null, title: string
): Metadata
export async function buildEntityNamePrefixedTranslatedMetadata(
  fetchEntityName: () => Promise<string | null>,
  titleSelector: (t: Translations) => string
): Promise<Metadata>

// Pattern 4: Entity name only — params, async fetch
export function buildEntityNameOnlyMetadata(
  entityName: string | null, fallbackTitle: string
): Metadata
export async function buildEntityNameOnlyTranslatedMetadata(
  fetchEntityName: () => Promise<string | null>,
  fallbackSelector: (t: Translations) => string
): Promise<Metadata>

// Pattern 5: Entity name formatted — params, async fetch, function-based
export function buildEntityNameFormattedMetadata(
  entityName: string | null,
  formatTitle: (name: string) => string,
  fallbackTitle?: string

  fetchEntityName: () => Promise<string | null>,
  formatTitle: (t: Translations, name: string) => string,
```

## Design Decisions

### Dual sync/async API
Each pattern has both a synchronous core (e.g., `buildEntityNamePrefixedMetadata`) that works with pre-fetched values, and an async translated variant (e.g., `buildEntityNamePrefixedTranslatedMetadata`) that internally calls `getLocale()` + `getTranslations()`. This lets consumers avoid importing `getLocale`/`getTranslations` directly — the async translated variants are the primary entry points for route files.

### Translation selector functions
Instead of passing namespace strings (e.g., `"dashboardTranslations.teacherFutureSchedule"`), selectors are type-safe arrow functions: `(t) => t.dashboardTranslations.teacherFutureSchedule.pageTitle`. This gives full compile-time type checking, IDE autocomplete, and refactoring support.

### Promise.all for parallel fetches
`buildEntityNamePrefixedTranslatedMetadata` and `buildEntityNameOnlyTranslatedMetadata` use `Promise.all` to fetch the entity name and translations concurrently, since they're independent operations. `buildEntityNameFormattedTranslatedMetadata` is sequential because it needs the translations root `t` to format the title.

### Metadata.title type handling
Next.js `Metadata.title` is `string | AbsoluteString | DefaultTemplateString`, not just `string`. The async helpers that destructure `metadata.title` from `buildTranslatedMetadata` use a `typeof title === "string"` guard before passing to the sync core functions, ensuring type safety.

### Fallback for format functions
`buildEntityNameFormattedTranslatedMetadata` has an optional `fallbackSelector` parameter. When omitted, the fallback is `formatTitle(t, "")` — matching the existing pattern in `teachers/[id]/schedule/weekly/page.tsx` which called `t.pageTitle("")` as the fallback. When the fallback differs (e.g., `subjects/[id]/page.tsx` falls back to `t.dashboardTranslations.subjects.pageTitle`), the selector is provided.

## Refactoring Example

**Before** (teachers/[id]/schedule/future/page.tsx):
```typescript
export async function generateMetadata({ params }): Promise<Metadata> {
  const { id } = await params;
  const locale = await getLocale();
  const t = getTranslations(locale).dashboardTranslations.teacherFutureSchedule;
  const teacherName = await getTeacherPageTitle(id);
  if (teacherName) {
    return { title: `${teacherName} — ${t.pageTitle}` };
  }
  return { title: t.pageTitle };
}
```

**After**:
```typescript
export async function generateMetadata({ params }): Promise<Metadata> {
  const { id } = await params;
  return buildEntityNamePrefixedTranslatedMetadata(
    () => getTeacherPageTitle(id),
    (t) => t.dashboardTranslations.teacherFutureSchedule.pageTitle,
  );
}
```
