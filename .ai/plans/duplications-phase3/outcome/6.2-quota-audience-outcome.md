## Scaffold Design

### `QuotaAudienceSection` (slot section config)

| Field | Type | Purpose |
|-------|------|---------|
| `label` | `string` | Section heading (e.g. `t.audience.remainingCredits`) |
| `emptyStateMessage` | `string` | No-data message below the label |
| `icon` | `SvgIconComponent?` | Optional MUI icon |
| `iconColor` | `string?` | Optional theme palette color (e.g. `"error.main"`, `"warning.main"`) |
| `iconLayout` | `"leading" \| "inline"?` | `"leading"`: icon beside content (Teacher/Supervisor); `"inline"`: icon beside label only (Supervisor analytics) |
| `highlighted` | `boolean?` | Primary section (elevation 4 vs 0) |

### `QuotaAudienceViewSharedProps` (scaffold props)

| Field | Type | Purpose |
|-------|------|---------|
| `title` | `string` | Audience card title |
| `sections` | `readonly QuotaAudienceSection[]` | Ordered list of sections |
| `cardContentSx` | `SxProps<Theme>?` | Optional extra sx for inner Box |

### Layout Variants

The scaffold handles 3 layout patterns through the `icon` + `iconLayout` fields:

1. **Plain** (Parent, Student): No icon; `Paper` with `Typography` label + message
2. **Leading icon** (Teacher, Supervisor sections 1–3): Icon + Box(label, message) in horizontal flex
3. **Inline icon** (Supervisor section 4): Box(icon, label) horizontal, then message below

## Thin Wrapper Pattern

Each audience view is now a thin wrapper:
1. Imports `QuotaAudienceViewShared` and `QuotaAudienceSection` type
2. Builds its section config array from `t.audience.*` translation labels
3. Renders `<QuotaAudienceViewShared {...} />`

Example (ParentQuotaView.tsx, 22 lines):
```tsx
function buildParentSections(t: StudentQuotaLabels): readonly QuotaAudienceSection[] {
  return [
    { label: t.audience.remainingCredits, emptyStateMessage: t.audience.noChildren, highlighted: true },
    { label: t.audience.activeQuotas, emptyStateMessage: t.audience.noChildren },
    { label: t.audience.onDemandPending, emptyStateMessage: t.audience.noChildren },
  ];
}

export function ParentQuotaView({ t }: Readonly<ParentQuotaViewProps>) {
  return <QuotaAudienceViewShared title={t.audience.parentTitle} sections={buildParentSections(t)} />;
}
```
