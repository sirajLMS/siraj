# Task 2.3 — Backend Service Intra-File Clone Elimination

## Summary

Eliminated 12 intra-file code clones across 9 backend service files by extracting duplicated blocks to named module-scope helper functions and private methods. All changes pass tsgo, biome, lint, and lint:type-aware. Service tests pass (2 pre-existing DB timeout failures in parent-onboarding tests are unrelated to this refactoring).

## Patterns Used

1. **Module-scope helper functions** for pure logic extraction (validation, duration calculation)
2. **Namespace-scope private methods** for service-specific helpers (permission checks, entity fetch + error throw)
3. **Type-safe approach**: No `as` casts or `oxlint-disable` comments used. Where Drizzle generics caused typing issues, inline queries with concrete columns were used instead to preserve full type inference.
4. **i18n**: All error messages use `getServerTranslations(locale, "namespace")` — no hardcoded strings.
5. **Logging**: Uses `logger` from `@/backend/lib/logger` — no `console.*`.
6. **Path aliases**: All imports use `@/` prefix with direct module imports.
