## Design Decisions

1. **`callProviderApi` returns `GenerateMeetingResult`** (not raw `Response`): Each provider's API call handles its own HTTP fetch, error parsing, and response mapping. This avoids the "body already used" issue where a shared error-checking helper would need to read `response.json()` eagerly, consuming the body before status-specific handling.

2. **`resolveAccessToken` is abstract**: Each provider has different org-credential token acquisition (Zoom: client_credentials, Teams: client_credentials with organizer, Google Meet: JWT-bearer exchange with service account). The per-user fallback flow is shared via `getPerUserAccessToken`.

3. **`tokenRefreshMarginMs` varies per provider**: Google Meet=60s, Zoom=60s, Teams=120s. Implemented as abstract property so each subclass provides its own value.

4. **Zoom uses `fetchWithTimeout` helper**: The Zoom adapter benefits from the shared fetch-with-timeout wrapper. Teams and Google Meet use `withTimeout` + manual `fetch()` because they need more control over request construction (Teams: organizer-based URL, Google Meet: JWT in headers).

5. **No `transformResponse` abstraction**: The original design mentioned `transformResponse` as an abstract method, but each provider's response format is completely different (Zoom returns a numeric ID, Teams returns a join URL, Google Meet returns a space object). The transformation logic lives inside each adapter's `callProviderApi` instead.

## Fixes Applied During Refactoring

1. **Oxlint `no-floating-promises`**: `assertResponseOk` in ZoomMeetingAdapter is async but was called without `await`. Fixed by adding `await` before both call sites.
2. **Oxlint `no-unsafe-type-assertion`**: All `as` casts replaced with type guards (`isRecord`) from the base class.
3. **No `oxlint-disable` comments**: None added — all issues fixed at root cause.
4. **"Body already used" error**: Zoom `assertResponseOk` only calls `parseErrorBody` when `!response.ok`, not eagerly before status checks. For 429 status, it checks headers without reading the body.
