- **URL**: https://github.com/oven-sh/bun/issues/10329
- **State**: **OPEN** (last updated 2025-11-25T01:45:48Z)
- **Labels**: bug, ecosystem, node:stream
- Posted April 2024; affects pooled SMTP transports under sustained use
- **Upstream status**: nodemailer maintainer `andris9` closed the parallel nodemailer/nodemailer#1644 with: *"Nodemailer has guaranteed support only for Node."* (July 25, 2024)
- **Relevance to Bun 1.3.14**: STILL APPLIES. The Bun issue remains open. nodemailer upstream formally disclaims Bun support. The plan's caution (line 317 / 558) — "prefer API providers in production" — is correctly worded.

### 4.2 Issue #26066 — Bun 1.3.x HTTPS hang regression
- **URL**: https://github.com/oven-sh/bun/issues/26066
- **State**: **STILL OPEN** (last updated 2026-07-10T23:47:21Z)
- Reported Jan 14, 2026; affects continuous HTTPS requests (esp. AWS SDK v3)
- **Most recent comment** (mdnjohn, 2026-07-10): *"I'm facing the same issue. I didn't encounter it during development, but after deploying to production I noticed that, after using the app for a while, requests start hanging. As far as I know, there isn't a real solution yet, other than falling back to Node.js. I'm on 1.3.14"*
- Multiple candidate fix PRs referenced: #30627 (TCP keepalive), #35272 (backpressure slot release), #36145/#36146 (idle timer absolute deadline). Maintainers have **NOT confirmed** #26066 is fully closed by any of these — the PR descriptions explicitly decline to add `Fixes #26066` lines because the root cause is still debated.
- **Relevance to Bun 1.3.14**: **#26066 IS REPRODUCIBLE ON 1.3.14** (per the most recent comment). The regression is NOT fixed. The `@smithy/fetch-http-handler` recommendation (plan line 314) is correctly justified — it bypasses `node:http`/`node:https` and uses global `fetch` instead, sidestepping the HTTP/1.1 request-slot exhaustion mechanism described in PR #35272.

## 6. Plan claim evaluation

### Plan line 314 — "Use `@smithy/fetch-http-handler` for Bun compatibility (avoids Bun 1.3.x HTTPS-hang #26066)"

**VERIFIED.**
- `@smithy/fetch-http-handler^5.6.13` is a direct bundled dep of `@aws-sdk/client-ses@3.1101.0` (`package.json:37`).
- #26066 is **STILL OPEN** on 1.3.14 (confirmed via the Jul 10, 2026 comment).
- The fetch-http-handler swaps the SDK transport from `node:http` (which trips the regression) to global `fetch` (Web API, sidesteps the HTTP/1.1 slot-exhaustion mechanism described in PR #35272).
- No edit required.

### Plan line 317 / 558 — "Nodemailer has historical Bun SMTP flakiness (#10329) — prefer API providers in production"

**VERIFIED.**
- #10329 is **STILL OPEN** (last updated Nov 25, 2025).
- nodemailer upstream maintainer (`andris9`) formally disclaims Bun support (nodemailer/nodemailer#1644, closed Jul 25, 2024 with the quoted statement).
- The "prefer API providers in production" guidance is appropriately conservative.
- No edit required.
