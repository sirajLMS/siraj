## Changes Made

### 1. Created Canonical Service: `backend/services/system/environment-config.service.ts`

Merged all resolver functionality from the deleted `backend/lib/env-config-resolver.ts` into the existing `environment-config.service.ts`:

**Read Path (from resolver):**
- `resolveEnvConfig(key: string)` — single-key DB-first/env-fallback resolution with TTL cache
- `resolveEnvConfigMany(keys: string[])` — batch resolution with concurrent DB lookups
- `invalidateEnvConfigCache(key?: string)` — cache invalidation (full or per-key)
- `getEnvConfigCacheStats()` — cache observability

**Cache Infrastructure:**
- Module-scoped singleton `Map<string, CacheEntry>` cache with lazy TTL expiry
- Configurable TTL via `ENV_CONFIG_CACHE_TTL_MS` env var (default 5 min)
- `isExcludedFromDb()` check — keys flagged `excludeFromDb: true` bypass DB & cache entirely
- Helper functions: `partitionKeysByDbEligibility`, `serveFromCache`, `lookupDbValueFor`, `recordResolvedKey`

**Write/Delete/List/Audit Paths (existing, preserved):**
- `listEnvConfigEntries()` — Settings tab list view with masked secrets
- `upsertEnvConfigOverride(input)` — create/update DB override + cache invalidation
- `deleteEnvConfigOverride(key)` — remove DB override + cache invalidation
- `auditEnvConfigChange(...)` — audit log emission with secret masking

**Removed Duplicated Helpers:**
- `descriptorIndex`, `getDescriptorIndex()` — consolidated single definition
- `toDbKey()`, `readFromProcessEnv()`, `ENV_SETTING_KEY_PREFIX` — single definition
- `getSettingsExposedDescriptor()`, `isExcludedFromDb()` — single definition
- `toEntryCategory()`, `resolveDbEligibleKey()` — single definition
