# 3.2 Currency Utility Resolution

## Status: COMPLETE

## Analysis

The duplication between `frontend/common/lib/currency.ts` and `frontend/common/lib/static-currency-catalog.ts` was **extractable duplication**, not intentional static data.

Both files contained identical copies of:
- The `CurrencyOption` type definition
- The full currency catalog array (32 currency entries with code, symbol, countryCode, flagEmoji)

`currency.ts` is the canonical module with utility functions; `static-currency-catalog.ts` was a redundant copy used only by `currencyStore.ts` as a static fallback.

## Resolution

**Decision: Consolidated into single canonical module (NO re-exports).**

### Changes

1. **Deleted** `frontend/common/lib/static-currency-catalog.ts` — the redundant copy.
2. **Modified** `frontend/common/stores/currencyStore.ts`:
   - Removed import of `staticCurrencyCatalog` from `static-currency-catalog`
   - Added import of `currencies` from `@/frontend/common/lib/currency`
   - Replaced all 3 references to `staticCurrencyCatalog` with `currencies`
3. **Updated JSDoc** in `frontend/common/lib/currency.ts` to clearly document that `currencies` is the single canonical source for static currency data (prevents future re-introduction of duplication).
