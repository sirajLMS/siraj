# Task 1.10: Consolidate resolve-localized.ts and localized-string.ts - Outcome

## Summary

Successfully consolidated the duplicate localized-string utilities by:
1. Creating `shared/lib/localized-string.ts` as the canonical shared implementation
2. Updating `frontend/common/lib/localized-string.ts` to re-export from shared and keep frontend-only helpers
3. Deleting `backend/db/repo/utils/resolve-localized.ts` entirely (NO re-export)
4. Updating all 5 backend importers to import from `@/shared/lib/localized-string`

## Changes Made

### File Created: `shared/lib/localized-string.ts`

Canonical shared module with 4 functions:
- `resolveLocalizedString(map, locale?)` — resolve a localized map to a single display string
- `setLocalizedString(existing, locale, value)` — set one locale's value (returns new object)
- `omitEmptyLocalizedString(map)` — drop entries whose value is empty/whitespace
- `localeJsonKey(locale?)` — SQL-safe locale key for jsonb extraction

Used `isAppLocale()` type guard instead of unsafe type assertion to satisfy oxlint `no-unsafe-type-assertion` rule.

### File Deleted: `backend/db/repo/utils/resolve-localized.ts`

Deleted entirely — no re-export. All importers updated to use `@/shared/lib/localized-string`.

### File Updated: `frontend/common/lib/localized-string.ts`

Now imports and re-exports the 4 shared functions from `@/shared/lib/localized-string`. Keeps frontend-only helpers locally:
- `removeLocalizedString(map, locale)` — remove a locale entry
- `hasRequiredLocalizedValue(map, requiredLocales)` — check required locales
- `pickInitialActiveLocale(uiLocale?)` — pick editing locale
- `unusedLocales(map)` — list locales with no value
- `normalizeContentLocale` re-exported for backward compat

### Backend Importers Updated (5 files)

1. `backend/services/auth/permission-group-simulation.service.ts` — `resolveLocalized` → `resolveLocalizedString`, `localeJsonKey` unchanged
2. `backend/services/auth/permission-management.service.ts` — `resolveLocalized` → `resolveLocalizedString`
3. `backend/services/auth/demo-auth.service.ts` — `resolveLocalized` → `resolveLocalizedString`
4. `backend/db/repo/teachers/staff-profile.repository.ts` — `resolveLocalized` → `resolveLocalizedString`, `localeJsonKey` unchanged
5. `backend/db/repo/permissions/permission-management.repository.ts` — `resolveLocalized` → `resolveLocalizedString`, `omitEmptyLocalized` → `omitEmptyLocalizedString`, `localeJsonKey` unchanged

### Doc Updated: `backend/db/repo/AGENTS.md`

Removed stale `(e.g. resolve-localized)` reference from the `utils/` directory description.
