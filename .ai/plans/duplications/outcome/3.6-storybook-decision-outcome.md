# Task 3.6: Storybook Story Deduplication Decision — Outcome

## Decision: Option B — jscpd ignore globs for `**/*.stories.tsx`

### Rationale

1. **138 story-vs-story clones** (4,374 lines / 17,463 tokens) were detected across 273 `.stories.tsx` files
2. Stories are **test artifacts** (not production code) that mirror the tier architecture (common/desktop/mobile)
3. The **components themselves have already been deduplicated** in Tasks 2.3–2.9 (StatusBadge, BaseDeleteDialog, MetricCard, etc.)
4. Extracting shared story factories would require ~25+ factory functions and still leave meta/arg-type boilerplate that's hard to abstract meaningfully
5. The design.md explicitly states: *"Stories are test artifacts; factory approach preferred but ignore is acceptable fallback"*
6. jscpd reports are for **production code quality** — stories are development tooling, not shipped code
7. REQ-14 allows either approach; ignoring stories reduces noise from 1,002 to ~826 relevant clones

### Implementation

Added `**/*.stories.tsx` to the `ignore` array in `.jscpd.json`:

```json
"ignore": [
  ...,
  "**/seeds/**",
  "**/migration/**",
  "**/*.stories.tsx"
]
```
