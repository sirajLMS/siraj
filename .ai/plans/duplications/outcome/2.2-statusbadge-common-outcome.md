## Changes Made

### File: `frontend/common/components/ui/badge/StatusBadge.tsx`

**Before:** 269 lines with fully duplicated color-resolution logic (`resolveStatusPaletteKey`, `getStatusColors`) identical to desktop and mobile variants.

**After:** 39 lines. The component is now a thin wrapper around `StatusBadgeShared`:

- Imports `StatusBadgeShared` from `@/frontend/common/components/ui/badge/StatusBadgeShared`
- Imports `StatusBadgeCategory` type from `@/frontend/common/components/ui/badge/types/statusBadgeShared.types`
- Re-exports `StatusBadgeCategory` type for backward compatibility with existing importers (e.g., `sessionStatusUtils.ts`)
- Passes common-tier slot configuration:
  - `boxPadding`: `(theme) => ({ paddingInline: theme.spacing(1.5), py: 0.5 })` (common box padding for non-icon variant)
- Preserves the `StatusBadgeProps` interface with same public API

### File: `frontend/common/components/ui/badge/StatusBadgeShared.tsx` (Scaffold)

Created as prerequisite (Task 2.1). The scaffold extracts the duplicated 199-line color-resolution logic shared across all three tiers:

- **`resolveStatusPaletteKey(category, status)`** — Maps (category, status) pairs to semantic palette keys (`active`, `pending`, `blocked`, `confirmed`, `completed`, `cancelled`)
- **`getStatusColors(theme, category, status)`** — Returns `{ backgroundColor, color }` using theme palette tokens
- **`StatusBadgeShared` component** — Renders Chip (with icon) or Box + Typography (without icon), accepting tier-specific slot props:
  - `chipDimensions` — per-size height and minWidth
  - `chipPaddingInline` — horizontal padding for Chip variant
  - `boxPadding` — padding for Box variant
  - `typographyProps` — variant, fontSize, textTransform, sx overrides

**Quality Fixes Applied:**
- Added `/* eslint-disable react-refresh/only-export-components */` to suppress Fast Refresh warnings (exporting shared functions alongside component)
- Changed `StatusBadgeScaffoldProps` from duplicated type alias to clean interface extending `StatusBadgeSharedProps & StatusBadgeSlotProps`

### File: `frontend/common/components/ui/badge/types/statusBadgeShared.types.ts`

Canonical type definitions for the scaffold:

- `StatusBadgeCategory` — Union of 12 categories
- `StatusPaletteKey` — Union of 6 semantic palette keys
- `StatusBadgeSharedProps` — Core props (category, status, label, size, icon)
- `StatusBadgeSlotProps` — Tier customization props (`chipDimensions`, `chipPaddingInline`, `boxPadding`, `typographyProps`)
- `ResolveStatusPaletteKeyFn`, `GetStatusColorsFn` — Function type signatures for shared logic

**Fixes Applied:**
- Extended `typographyProps.textTransform` to allow `"uppercase" | "none"` (scaffold used `"none"`)
- Made `boxPadding` return type `Record<string, unknown> | undefined` (scaffold handles `undefined`)

### File: `frontend/common/components/ui/badge/index.ts`

Updated barrel export:
- Exports `StatusBadge` (main component)
- Exports `StatusBadgeCategory` from types (canonical source)
- Exports `StatusBadgeShared`, `resolveStatusPaletteKey`, `getStatusColors`, `StatusBadgeScaffoldProps` from scaffold
- Exports all shared types from types file
- Removed redundant `export *` patterns to avoid duplicate exports
