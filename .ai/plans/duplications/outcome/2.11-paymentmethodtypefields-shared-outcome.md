## Carry-Over Knowledge
- The scaffold pattern (`*Shared.tsx` with slot props + options + translations prop) follows the established `baseDeleteDialogShared.tsx` precedent (task 2.6)
- Slot props are typed as `React.ComponentType<{ precisely-typed-props }>` — NOT render props — for type safety and ergonomics
- Tier variants will pass their own component implementations as slots (e.g., `MobileLocalizedStringFormField` as `LocalizedStringFormField`)
- Mobile tier uses `stackSpacing={2}` + `textFieldSize="small"`; Common/Desktop use `stackSpacing=2` (default) + no `textFieldSize`
- `tTypeFields` translation object passed as prop avoids hook call inside generic component (cleaner SSR and testing)
