# 2.4 — Refactor MobileStatusBadge to consume scaffold

## Summary

Refactored `frontend/mobile/components/ui/badge/MobileStatusBadge.tsx` to consume the shared `StatusBadgeShared` scaffold instead of duplicating color resolution, chip structure, and layout logic.

## Changes

### `MobileStatusBadge.tsx`

**Before:** ~120 lines with inline color mapping, theme color callbacks, chip sizing, typography variants, and full render logic — duplicating `common/StatusBadge.tsx` and `desktop/DesktopStatusBadge.tsx`.

**After:** ~75 lines (including docs). The component is now a thin wrapper that:
- Imports `StatusBadgeShared` from `@/frontend/common/components/ui/badge/StatusBadgeShared`
- Imports shared types from `@/frontend/common/components/ui/badge/types/statusBadgeShared.types`
- Delegates all structure/color/typography to the scaffold
- Passes mobile-specific values via slot props

## Mobile-specific preserved behavior

All differences from the desktop/common variants are preserved via slot props:

| Slot prop | Mobile value | Scaffold default |
|---|---|---|
| `chipDimensions.small.height` | 20 | 24 |
| `chipDimensions.small.minWidth` | 72 | 72 |
| `chipDimensions.medium.height` | 24 | 28 |
| `chipDimensions.medium.minWidth` | 84 | 72 |
| `typographyProps.fontSize` | "0.7rem" for `labelUppercase`, `undefined` for `labelSm` | (no override) |
| `typographyProps.textTransform` | "uppercase" for `labelUppercase` only | (no transform) |
| `boxPadding` | `{ minWidth: chipMinWidth, paddingInline: theme.spacing(1), py: 0.25 }` | (no padding) |

### Barrel exports

`frontend/mobile/components/ui/badge/index.ts` unchanged — still re-exports `MobileStatusBadge`, `MobileStatusBadgeCategory`, `MobileStatusBadgeProps`.
