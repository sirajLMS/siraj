# Plan: Delete All S7763 Re-Exports and Update Consumers

## Goal

Delete all 37 `typescript:S7763` re-export issues from SonarQube. No re-exports, no type aliases, no export aliases. Consumers import directly from the original source — no renaming.

## Key Principle

S7763 flags **pure pass-through re-exports** (import → re-export with no local use). When a file imports a symbol, uses it locally, AND re-exports it, S7763 does NOT flag it. Per the user's instruction ("no re-exports at all"), we delete the entire `export { }` / `export type { }` block — even symbols used locally are removed from the re-export (they stay in the import). All consumers of any re-exported symbol are updated to import from the original source.
