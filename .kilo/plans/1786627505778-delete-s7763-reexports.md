## Risks

1. **Barrel cascades:** `frontend/common/lib/index.ts` does `export * from "./meetingJoinAction"` — this is a barrel `export *`, NOT a named re-export, and is NOT flagged by S7763. Leave as-is.
2. **Storybook stories:** 2 stories reference deleted `DesktopFormSuccessSnackbar`/`MobileFormSuccessSnackbar` components — need to update or delete.
3. **`parentOnboardingShared.options.tsx`** imports both desktop and mobile snackbar variants — needs both updated to `FormSuccessSnackbar`.

5. **`frontend/common/components/ui/display/meetingConfig/index.ts` barrel** exports `MeetingJoinEmptyRole` from `./types` (line 13) — this is a barrel `export type { }` which is allowed per AGENTS.md. The `ClassDetailsToolbarArea.tsx` consumer can import from this barrel.
